## Решения, которые вносит приёмка

1. **E1** (Р1): один экран `/settings`, шесть разделов, навигация-якоря, одна прокрутка.
2. **E2** (Р2): таблица способов второго фактора с датами и QR-кодом, который рисуется в браузере.
3. **E3** (Р3): ключи и сессии переезжают в общую `ResourceTable`, у ключа появляются даты.
4. **E4** (Р4): запасные коды показываются один раз, есть «Скачать (.txt)», предупреждение при `K ≤ 2`.
5. **E5** (Р5): окно повышения берёт перечень из `stepUpMethods`. Порядок показа задаёт консоль, по умолчанию выбирается сильнейший способ, а запасной код — никогда. Новая ветка ключа: `begin` → `credentials.get` → `step-up`.
6. **E6** (Р6): опасные действия получают диалог с последствием словами.
7. **E7** (Р7): «выключено на установке» показывается состоянием раздела. Для `Удалить` при `stepUpMethods = []` выводится сообщение, `Revoke` не выпускается.
8. **E8** (Р8, Р9): пустые состояния и доступность.
9. **E9** (Р10): 27-я запись ретрансляции края; `OWN_STEP_UP_METHODS` получает `webauthn`.
