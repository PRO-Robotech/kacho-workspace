# Второй проход пересверки на отпечаток ред. 12 LINE-A-1 — здесь только указатель

Это не запись ревью. Шапки, вердикта и отпечатка здесь нет.

Второй проход пересверки классов на отпечаток замысла ред. 12 (задача kacho-workspace#723, итог
**unmapped: `RV-1`**) перенесён **дословно** в файл
`48cb2d72f29b8813a28f50589b06d526d2a2a682396e142b706fffc1577896b9.md` этого же каталога. Он лежит
там после текста первого прохода, в разделе «ВТОРОЙ ПРОХОД НА ТОТ ЖЕ ОТПЕЧАТОК». Прежнее содержимое
этого пути — коммит `56e90bd8`, `sha256` `8730092da8bbeb907ee74fd398971b051efbd5083318aa56e33f9c051bccc2a8`.
Последние 40720 байт файла-приёмника дают тот же `sha256`.

**Почему текст перенесён.** `scripts/docs-gate/check-06-revalidation-superseded-complete.py`
признаёт записью только файл, чьё имя совпадает с отпечатком прочитанного предмета. Имя с
суффиксом задачи он судит находкой. Строку ведомости `SUPERSEDED.yaml` о таком файле он тоже судит
находкой: строки сверяются только с файлами из пространства имён отпечатков. Поэтому два прохода
об одном отпечатке законно лежат в одном файле.

**Почему путь не снят.** На этот путь ссылаются замысел LINE-A-1 ред. 13 (история редакций, врезка
переписи, строка ред. 12 таблицы, врезка «Что правит ред. 13») и ведомость `SUPERSEDED.yaml`. Если
снять путь, их утверждения будут указывать туда, где предмета нет.
