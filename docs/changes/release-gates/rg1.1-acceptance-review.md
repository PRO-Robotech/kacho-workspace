Эта ветвь требует отдельной процессной регрессии с законным близнецом. Пробы отсутствия trivy и провала после изменения не заменяют её. Рецензент отнёс условие к техническому обеспечению уже принятого инварианта #2175, без изменения одобренных GWT.
