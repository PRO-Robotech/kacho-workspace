# Независимая операционная диагностика b5fa

Автор доказательств — /root/truth_tests; автор пакета механически скопировал семь
отчётов без изменения байтов. Точные пути и SHA256 находятся в copy-bindings.json.
Исходный OPERATIONAL_MANIFEST.json связывает 95 внешних файлов; все 95 проверены
перед копированием. Полный набор потоков процессов остаётся в указанном внешнем
каталоге AUD. Этот каталог содержит только семь выбранных безопасных отчётов,
копировочную привязку и данное пояснение.

Свидетельства подтверждают настоящие частичные чтения для CI-EBT-09 и CI-EBT-11,
сохранение одной находки и потерю причины baseline в текущем CI-EBT-10. Таблица
будущих счётчиков совпадает с scenario-matrix.json. Исторические авторские
наблюдения в evidence/diagnostic-b5fa сохранены как отдельный исходный срез.

Это независимая операционная диагностика, а не acceptance/design approval,
независимый RED holder или разрешение исходника. Выполнены 40 диагностических
команд и два отдельных public запуска под strace; все процессы завершены.
Канонические subjects сохраняют статус DRAFT, lifecycle остаётся ISSUE_READY.
