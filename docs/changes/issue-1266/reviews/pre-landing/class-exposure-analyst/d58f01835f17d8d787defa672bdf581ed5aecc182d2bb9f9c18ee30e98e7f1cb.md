## Решения, которые вносит набор

1. KA1 Р1: третий исход «состояние удостоверения не установлено» (`503`, носитель цел) на
   трёх полосах.
2. KA1 Р2: один отказ `401`, побайтово одинаковый для всех причин. Полоса сессии гасит
   носитель.
3. KA1 Р3: исключение из Р2, указание повысить уровень.
4. KA1 Р4: две ручки бюджета вызовов без умолчания, судятся при старте.
5. KA1 Р5: канон издателя в одном месте. Если две формы дают одну каноническую, старт
   отказывает.

7. F1 §4 и §6.6–6.8, сторона потребителя (край): срок обязателен; адресат и издатель
   обязательны; перечень алгоритмов непуст; незнакомый ключ пропускается; вынужденный
   перезапрос ограничен по частоте; `kid` и издатель — недоверенные входы.
8. F8 Р3: адрес, которого консоль не ведёт, отвечает названной страницей. S3 Р1 снимает вид
   `not-served` вместе с его страницей.
9. F8 Р6: экран наблюдается переписью обращений.
10. F8 Р10, S3 Р7, S4 Р6, S6 Р5: перевыпуск носителя упорядочивает консоль. Перечень глаголов
    закрыт.
11. F8 Р7, S3 Р8, S4 Р8, S5 Р8: ось источника — общий ресурс прогона. Сумма долей судится
    против окна стенда.
12. S4 Р4: консоль снимает поля сериализации браузера. S4 Р5: отказ браузера — один свой
    текст, отказ службы — дословно.

    через очередь смены субъекта службы.
