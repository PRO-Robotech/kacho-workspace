`measurement-discipline` («Форма числа», «Радиус»), `gate-authoring`
и `verdict-and-landing`. Основание — собственные измерения закреплённого дерева
в design, не числа из issue. Исходный body #2696 уже содержит иной census.

Нового runtime external call, async path или sentinel нет. D5 добавляет обычную
release dependency на corelib; сетевое отсутствие опубликованной версии даёт
непоставленный результат, не освобождение. В design каждому
item соответствует решение; независимая роль должна подтвердить initial на
acceptance SHA и отдельную revalidation на design SHA. Этот файл полномочий
следующей стадии не создаёт. Содержательную истинность комментариев держит
review с первичными свидетельствами; машинный общий prose parser не нужен.
