Экземпляр относится к текущей подписи, пережившей свой предмет. Его радиус
здесь — указанная fixture и её связь с объявлением expectation. Это отдельный
файл от исправления шапки #1439; прежнее узкое закрытие #1439 сохраняет смысл.
Историческое объяснение снятия #1255 и датированные WATCH-свидетельства
не меняются. Whole-class closure для всего корпуса комментариев не заявляется.

`e3cfb84acccb42e3c1d9d34db1e332f8b48625826e0cd1aa76caadae9fad3629`.
Предлагается новый ограниченный addendum с собственным exact subject hash;

## Предлагаемые держатели и порядок

1. Независимый reviewer проверяет нынешнюю ложную подпись на указанном срезе
   и принимает либо отклоняет CI-DT-A1-01..03. Затем root выпускает отдельный
   source transition на hash этого addendum. Наличие файла допуск не создаёт.
2. Исполнитель удаляет ровно две строки. Verifier читает исходник из обоих
   Git SHA и проверяет точное равенство candidate с baseline после этого
   единственного удаления. Дополнительно сравнивает tokens/AST без whitelist.
   Вход пуст, непрочитан либо не содержит объявления — отсутствие доказательства.
3. У одноразового comparator должны быть собственные положительный
   comment-only контроль и отрицательные one-token/empty-input контроли.
   Сравнение четырёх других Go-файлов CI-DT-1 само по себе этот пятый файл
   не покрывает. Инструмент и команды сохраняются с SHA-256 и исходными потоками.
4. До и после из корня Kachō, с `GOWORK=off`, внешним `TMPDIR` и очищенными
   `GIT_*`, выполняются команды:

   ```sh
   go test ./internal/repohygiene -list '^Test(SubscriptionFormShape|SubscriptionShape)' -count=1
   go test ./internal/repohygiene -run '^Test(SubscriptionFormShape|SubscriptionShape)' -count=1 -json -timeout=5m
   ```

   Число и имена фиксируются из реального вывода на exact SHA; нулевой набор,
   ошибка окружения или пропуск не GREEN. Это сохранность исполнения,
   семантическую ложность комментария устанавливает reviewer по предмету.
5. Независимый post-diff review и root convergence связывают исход с actual
   diff и всеми тремя ID. Проверка в main предшествует закрытию #2711.

Пока это предложение: source test-файл не изменён, addendum не принят,
новый comparator для него не реализован и независимого GREEN по нему нет.
