## Не блокирует — заказ к полосе провязки (S9)

Предикат сужения потока строится картой по слову вида журнала с умолчанием на
отношение чтения ресурсов; у типа объекта ленты это отношение не объявлено. При
провязке ключа ленты карта обязана получить для вида ленты отношение, которое модель
у этого типа объявляет, и пробу «подписчик без права на ленту строку сигнала не
получает, поток прочих подписчиков не рвётся» с близнецом — читателем ленты. Сегодня
путь не достижим (порт не провязан), исход при расхождении — отказ, а не раскрытие.
