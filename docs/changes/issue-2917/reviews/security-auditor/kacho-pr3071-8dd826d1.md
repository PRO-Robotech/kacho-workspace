## Поверхность

- Новых RPC, слушателей, записей каталога прав и отношений модели нет. Новая запись таблицы путей
  формы — предъявление кода регистрации; признак ограничителя стоит ровно у двух путей, ставящих письмо
  на адрес из тела; монтаж корня отказывает и при звене без таких записей, и при записях без звена.
- Адрес клиента: один оператор на модель прав, ретрансляцию и ключи звена; число прыжков — обязательный
  параметр без умолчания, нулевое значение типа отвергается сборкой корня. Прежние две ручки — в ведомости
  снятых.
- Звено: принадлежность пути решается до любого обращения к хранилищу; адрес, не разбираемый как литерал
  IP, — закрытый отказ; вызов подписан HMAC-SHA256 (сравнение постоянного времени), срок и сложность
  внутри подписи, одноразовость — первичным ключом в транзакции решения, фиксация только при пропуске;
  доказательство ниже сложности ступени — новый вызов; ветки «хранилище не ответило → пропустить» нет.
- SQL звена и уборки — только параметры; инварианты на уровне схемы (CHECK длины идентификаторов,
  непустой ключ, единственная строка ведра).
- Секрет подписи: только из файла по абсолютному каноническому пути, обычный файл, ≥ 32 байт; в журнал
  идёт путь, значение закрыто меткой. Ключи (адреса) в журнал и в метки метрик не попадают; метрики
  звена без меток.
- Публичные тексты (страницы, тело PR, сообщения коммитов) признак восстановимости проходят; атрибуции
