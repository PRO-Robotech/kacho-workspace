## Решения, которые вносят документы

**level-two (KN747).**
- **D1.** Полы `BeginRegistration`, `FinishRegistration` и `Revoke` поднимаются до «2» (Р3).
- **D2.** Заведение кода `enroll`/`confirm` у личности с ключом требует «2». Условие: «сессия «2» либо перечень ключей прочитан и пуст» (Р4).
- **D3.** Нечитаемый перечень ключей означает `503`/14, а не «ключа нет» (Р4, инв. 6).
- **D4.** Отказ по уровню на полосе формы — форма Ф11 Р11 с одним объявлением текста (инв. 3).
- **D5.** Порядок суждения: сессия → уровень → свежесть → состояние (Р3, Р4).
- **D6.** Отказ по уровню не меняет состояния (инв. 4).
- **D7.** Порог задан отношением, а не литералом: пол трёх глаголов не ниже пола `UserTokenService/Issue` (инв. 1, 2).
- **D8.** Ключи, заведённые до правки, снимаются шагом посадки на стендах, без миграции (Р6).
- **D9.** Страницы называют один порог (Р7).

**email-change (EC).**
- **E1.** Два новых глагола полосы формы и новые значения четырёх закрытых словарей (Р1, Р7, Р8).
- **E2.** Уровень на обоих глаголах зависит от заведённого. Ожидающее заведение способом не считается (Р2, ред. 3).
- **E3.** Нечитаемое заведённое означает `503`/14 (Р2).
- **E4.** Порядок суждения: сессия → положение → уровень → свежесть → поля (Р2).
- **E5.** Отказ по уровню ничего не пишет и попытку кода не засчитывает (Р2).
- **E6.** Занятый адрес на запросе неотличим от свободного, а уникальность держит ключ базы (Р4).
- **E7.** Код однократен, привязан к человеку и к адресу; новый запрос вытесняет старый код; число попыток ограничено (Р5).
- **E8.** Темп считается по принятому запросу и по окну адресата, списывается одинаково для занятого и свободного адреса (Р6).
- **E9.** Исход смены выполняется одной транзакцией из восьми шагов (Р8).
- **E10.** Один законный писатель адреса и новый производитель очереди смены субъекта (Р9).
- **E11.** Новое sentinel-значение: пустая свёртка кода означает запрос на занятый адрес (Р4, следствие формы хранения).

## Чего измерить нельзя

- **Полнота переписи способов «2» на будущих ревизиях.** Предикат по писателям на сегодня
  есть, но гейта, который его держит, нет. Число верно только для 3066c7b6a.
- **Полный путь p95 запроса смены с постановкой письма.** Повтор в интервале профиля
  отвечает `429` (так сказано в самом `DoD-proof`). Значит, число 2,30 мс относится к пути
  «резолв → два чтения уровня → транзакция до отказа темпа», а не к принятому запросу.
- **Свойство Р4 «ответ побайтово тот же» на крае.** Прочитано тело и заголовки, о прочих
  наблюдаемых свойствах ответа документ ничего не утверждает. Отдельный вопрос передан
  security-auditor вне этой записи (`security-disclosure.md`).
