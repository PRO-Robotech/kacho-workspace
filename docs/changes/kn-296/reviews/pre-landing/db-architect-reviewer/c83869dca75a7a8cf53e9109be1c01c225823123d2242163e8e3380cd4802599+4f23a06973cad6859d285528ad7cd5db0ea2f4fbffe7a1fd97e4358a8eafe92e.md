## Критические (блокируют посадку)

1. **[PARTIAL-UNIQUE без исхода под конкуренцией] Замещение испытания входа ключом под гонкой отдаёт 503.**
   - Где: `kaname internal/repo/kaname/pg/access_key_login_repo.go:65-75 @9a78fc21` (`IssueChallenge`: `DELETE … WHERE
     form_context=$1 AND consumed_at IS NULL`, затем `INSERT` в транзакции read committed) и ключ
     `internal/migrations/20261005032942_login_challenge_is_bound_to_the_form_context.sql:74 @9a78fc21`
     (`access_key_login_challenges_live_context_idx … WHERE consumed_at IS NULL`).
   - Сценарий: две выдачи `begin` под одним контекстом формы идут одновременно. Это обычный случай: условный показ ключа
     при загрузке плюс нажатие кнопки, двойной клик или повтор клиента. `DELETE` второй транзакции не видит
     незафиксированную строку первой и снимает ноль строк. Её `INSERT` ждёт запись индекса первой и после фиксации
     получает `23505`. Use-case `internal/apps/kaname/api/humansession/access_key_login.go:219-221` переводит любую ошибку
     в `ErrStoreUnavailable` (503) и пишет метрику `AccessKeyLoginStoreFailed`. Итог: Ф13-03 «второе испытание замещает
     первое» под конкуренцией не выполняется, а сигнал отказа хранилища ложный. Инвариант «одно живое на контекст» база
     держит, но исход проигравшего не тот, что обещает приёмка.
   - Пробы с конкурирующими транзакциями на этот частичный ключ нет. `TestF13_03_SecondChallengeReplacesTheFirst`
     последовательный. Индекс не упоминается ни в одном тесте, кроме `pgmaperr_check_value_lane_test.go`.
   - Требование: замещать одним оператором на частичном ключе, например `INSERT … ON CONFLICT (form_context) WHERE
     consumed_at IS NULL DO UPDATE SET challenge=EXCLUDED.challenge, issued_at=now(), expires_at=…`, либо сериализовать
     выдачи контекста механизмом базы. Нужна красная проба: N горутин выдают под одним контекстом, все получают успех,
     живая строка остаётся одна, и потребляется ровно испытание последней зафиксированной выдачи.
   - Вернуть: автору repo-слоя полосы Ф13 (kaname#613) — правка Go. Пробу пишет `integration-tester`. Миграция не
     меняется.
