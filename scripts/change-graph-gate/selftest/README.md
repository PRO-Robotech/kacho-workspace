# Пробы ядра SDD-1

Каталог принадлежит **implementation diff** (приёмка §6): здесь доказывается
испытуемый — `cglib` и оснастка гейта, — а не pre-RED driver. Проверки driver'а
живут отдельно, в `tests/selfcheck/`.

Каждая проба печатает **объём осмотренного** и различает три исхода: `0` — все
утверждения прошли, `1` — есть провалившееся, `2` — проба беспредметна (нечего
было проверять). Третий не вычитается из вердикта и не зачитывается в успех.

| проба | предмет | цена |
|---|---|---:|
| `prove.py` | тройка испытуемого на каждом объявленном кейсе плюс собственные отказы ядра | ~20 с |
| `prove_census_policy.py` | правила `cg.census` и `cg.policy` умеют упасть на дефекте и молчат на законном близнеце | секунды |
| `prove_run_progress.py` | долгий прогон `inject.py` не молчит: сброс буфера и объявление ДО прогона | ~80 с |
| `inject.py` | `prove.py` СПОСОБЕН упасть — по каждой инъекции краснеют ровно названные утверждения | ~20 с × (инъекций + 1) |

```sh
python3 scripts/change-graph-gate/selftest/prove.py
python3 scripts/change-graph-gate/selftest/prove_census_policy.py
python3 scripts/change-graph-gate/selftest/prove_run_progress.py
python3 scripts/change-graph-gate/selftest/inject.py            # долго
python3 scripts/change-graph-gate/selftest/inject.py '<часть имени>'   # одна инъекция
```

## Почему `inject.py` печатает по мере прохождения

Полный прогон — инъекций три с лишним десятка, и каждая есть полный прогон
`prove.py`. Пока прогон молчит, «идёт» и «повис» неотличимы, а долгое молчание
провоцирует снять его своим пределом — снятый же прогон даёт **третью
категорию** исхода, которую легко прочесть как красное.

Поэтому: шапка называет, сколько инъекций объявлено и сколько к прогону; строка
`ИДЁТ` печатается **до** прогона, чтобы остановка была видна на имени инъекции;
каждая строка идёт со **сбросом буфера** — вывод почти всегда перенаправляют, а
у неинтерактивного `stdout` буферизация блочная, и без сброса первые килобайты
строк сидят в буфере невидимо.

Отбор по подстроке имени существует и честен: при отборе перепись печатает,
сколько инъекций осмотрено из скольких объявленных, — «доказано 1 из 1» не
читается как «доказаны все». Негодный отбор отвергается **до** контрольного
прогона, а не после него.

Держится это `prove_run_progress.py`: он читает вывод из **файла** (у терминала
блочной буферизации нет, и на нём проба была бы вакуумной), снимает
`PYTHONUNBUFFERED` из окружения потомка и по каждому утверждению держит рядом
дерево, где свойство снято.
