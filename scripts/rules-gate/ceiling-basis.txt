# второй редакции стояло «такого тела не существовало НИКОГДА». Это было ЛОЖНО.
# Обход по ОБЪЕКТАМ ХРАНИЛИЩА шире: `git cat-file --batch-all-objects` даёт
# 35 348 объектов, из них 12 900 blob, и ровно один имеет размер 89 176 Б —

# выглядело проверенным», а ЗАМЕР ПО НЕЗАКОММИЧЕННОМУ СОСТОЯНИЮ: замер верен в
# момент снятия и становится неверен, как только рабочее дерево уехало.
# ПРОТИВОЯДИЕ — РЕВИЗИЯ РЯДОМ С ЧИСЛОМ, и она проставлена у каждого числа ниже.
# Предикат перемера — тот же `body_size`, что и в check-02 (файл минус
# frontmatter), по НАЗВАННОЙ ревизии:
#   git show <ревизия>:<файл> | python3 -c "import sys,re; d=sys.stdin.buffer.read();
#   m=re.match(rb'^---[ \t]*\r?\n.*?\r?\n---[ \t]*\r?\n',d,re.S);
