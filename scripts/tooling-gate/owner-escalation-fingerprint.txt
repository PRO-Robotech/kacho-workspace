# когда пункт сняли, и когда дописали абзац-оговорку, не тронув ни одной старой
# буквы. Поднять гейт обратно можно только вписав сюда новый отпечаток — тем же
# изменением, что и правку, строками, которые видно в диффе. Генератора для этого
# файла в наборе НЕТ намеренно: скрипт «обнови отпечаток» вернул бы поступок в
# разряд побочных эффектов, его запускали бы не глядя. Строки для вставки печатает
# сам гейт; дату и основание он оставляет угловыми скобками и объявляет находкой,
# если их вписали как есть.
#
# СТРОКА УЗАКОНИВАНИЯ НАЗЫВАЕТ СВОЙ ОТПЕЧАТОК — и это не украшение. В прежней
# редакции механизма (снятый `scripts/rules-gate/check-10`) основание судилось НА
# ПРИСУТСТВИЕ: новый отпечаток со старым основанием давал зелёное, и файл начинал
# нести утверждение, пережившее свой предмет. Здесь `отпечаток <16 знаков>` обязан
# совпадать с первыми 16 знаками `ИТОГО`; иначе — находка.
#
# ФОРМА: `<sha256 строки>\t<первые 64 знака строки>` — по одной записи на
# непустую строку раздела, в порядке их следования. Итог по разделу целиком —
# строка `ИТОГО`. Построчные записи нужны, чтобы находка называла, ЧТО именно
# дописали или сняли, а не только «разошлось».
