# adapter-gate — производное оснастки сходится со своим источником

## Предмет

Оснастка Kachō живёт **в единственном экземпляре** — `.claude/` воркспейса плюс корневой
`CLAUDE.md` (`.claude/rules/ai-tooling.md` §Модель распространения). Среды, читающие
`AGENTS.md`, `.agents/skills/` и `.codex/`, получают её **проекцию**.

Проекция **отслеживаемая**. Это решение, а не умолчание: непроверяемое производное
неотличимо от произвольного — расхождение входа и выхода тогда не обнаруживается ничем, а
выход при этом читается как утверждение об оснастке.

| | |
|---|---|
| владение | `.claude/adapters.yaml` — единственное объявление |
| генератор | `scripts/adapter/generate.py` |
| норма | `.claude/rules/change-graph.md` §Оснастка |
| напоминание в момент | `.claude/hooks/change-graph-reminder.sh` |

## Три состояния, каждое из которых выглядит как исправное дерево

1. **производное правлено руками** — правка уедет при следующей регенерации, и до тех пор
   выход утверждает об оснастке то, чего в ней нет;
2. **вход правлен, производное не перегенерировано** — выход описывает вчерашнюю оснастку;
3. **генератор недетерминирован** — расхождение приходит через раз, поэтому проверка №2
   краснеет на исправном дереве и зеленеет на испорченном.

Ни одно из трёх не даёт ни конфликта при слиянии, ни красного где-либо ещё.

## Проверки

| проверка | что утверждает |
|---|---|
| `check-01-manifest-matches-tree` | точный набор манифеста совпадает с отслеживаемым деревом — **в обе стороны** |
| `check-02-derived-matches-regeneration` | производное **побайтово** равно регенерации во временный каталог |
| `check-03-regeneration-deterministic` | два прогона на неизменных входах дают один результат |
| `check-04-canonical-case` | в порождённом нет **заглавной** формы имени каталога второй среды |
| `check-05-generated-paths-portable` | в порождённом нет абсолютного пути, **внесённого генератором** |
| `check-06-inputs-are-canonical` | генератор читает только канонические входы — проверено **исходом**, не чтением исходника |
| `check-07-skills-roster-matches-tree` | перечень пакетов манифеста совпадает со скилами оснастки |

Вычисление у всех семи одно — `probe.py`: семь копий регенерации разошлись бы молча.
Проверки остаются семью файлами, потому что у каждой свой вердикт и свой объём осмотренного.

## Исходы — ТРИ, и третий не засчитывается в успех

```
0 — рассмотрено N, находок 0
1 — НАХОДКА, либо пустой обход (о дереве не прочитано ничего)
2 — БЕЗ ПРЕДМЕТА: сверять не с чем (нет манифеста, дерево не под git)
```

Находка объявляется **первой**: набор, где есть и находка, и беспредметная проверка,
выходит единицей. Обратный порядок сделал бы «без предмета» маской.

## Чем доказано, что набор способен упасть

```sh
bash scripts/adapter-gate/inject.sh     # 25 утверждений, 7 осей, обе стороны
```

По каждой оси вносится настоящий дефект (проверка обязана покраснеть) и рядом ставится
**законный близнец** той же формы (проверка обязана смолчать). Без близнеца проверка ловила
бы форму, а не существо, и первый ложный срабат её отключил бы.

Отдельно проверено несущее требование приёмки: **чужой пакет не маскирует расхождение
владеемого** — при неизменном постороннем пакете расхождение владеемого выхода всё равно
находится.

**Инъекция нашла четыре дефекта в самом наборе**, и ни один не был виден чтением:

| дефект | почему чтение его не показывало |
|---|---|
| `git ls-files` **экранирует** не-ASCII путь — выход с таким именем был невидим | код выглядел верным; предикат просто не совпадал |
| проба каноничности подавала **несуществующий** путь | снятая защита падала на «файла нет» тем же типом ошибки |
| предикат сравнивал **подстроку**: `«НЕ ОТКАЗАЛ»` содержит `«ОТКАЗАЛ»` | предикат совпадал с собственным отрицанием |
| инъекция искала строку без экранирования | замена молча не применялась |

## Что этот набор НЕ проверяет — сказано прямо

- **не судит содержание** производного: что порождённый текст верен по существу, здесь не
  проверяется ничем. Он равен тому, что даёт генератор из входов, — и только;
- **не проверяет, что вторая среда его читает.** Провязка на её стороне за пределами
  дерева, и утверждать о ней отсюда нельзя;
- **не сторожит чужие пакеты.** Пакет вне манифеста не читается, не пишется и не удаляется.
