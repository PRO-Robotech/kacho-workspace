# vault-gate — ведомые записки хранилища и учётные данные во всём хранилище

**Предмет с 2026-10-16** (решение диспетчера по замеру: записки читали 0,86 %
запусков, 574 из 840 записок задач показывали «в работе» при закрытой задаче):
хранилище `obsidian/kacho/` сужено до **`lessons/` и `runbooks/`**. Прочие каталоги —
замороженный архив, источник правды о задаче, коде и рёбрах — трекер, git и код
(`obsidian/kacho/CLAUDE.md`). Архив не правится и потому не судится оболочкой и
связностью; учётные данные судятся во **всём** хранилище — оно публично.

Набор устроен как `scripts/skills-gate/`: `check-NN-*.sh` выносят исход кодом
(`0` — чисто, `1` — находки, `2` — предпосылки нет), `run-all.sh` сводит один
вердикт из числа, `inject.sh` доказывает, что гейт **способен упасть** и
**способен смолчать**.

## Прогон

```bash
./scripts/vault-gate/run-all.sh
./scripts/vault-gate/inject.sh      # единый вход: все inject-<N>
```

Монорепо продукта набору больше не нужно: проверки, сверявшие записки с его
деревом (прежний check-01) и указатель (check-04, check-05), сняты вместе с заморозкой.

## Три исхода, а не два

`run-all.sh` не засчитывает VOID (код 2) за успех и отказывается выносить вердикт,
когда проверок рассмотрено ноль; находка объявляется первой. Свойство держит
`scripts/tooling-gate/check-07-runner-void-distinct-from-finding.sh`.

## check-01 — в хранилище нет учётных данных

**Находка:** во ВСЁМ хранилище, архив тоже, — заголовок закрытого ключа PEM, токен
GitHub, JWT, токен Slack, присваивание учётному ключу литерала из букв и цифр длиной
от 12. Печатаются файл, строка и форма, **значение — нет**: вывод гейта сам публичен
в журнале конвейера. Имя ресурса без цифр и заглушки (`<…>`, `{{…}}`, `${…}`) —
законные близнецы.

## check-02 — ссылка из ведомой записки ведёт в существующий файл

**Находка:** wikilink из `lessons/` или `runbooks/`, который не резолвится ни одним из
трёх правил Obsidian (путь от файла-источника → путь от корня хранилища → базовое
имя где угодно). Цель ищется во всём хранилище: ссылка из урока в архив законна.

**Храповик двусторонний и по перечню.** Основание — `dangling-baseline.txt`: цель и
число ссылок на неё. Новая цель роняет гейт; исчезнувшая — тоже, с требованием
переписать основание тем же коммитом (`--write-baseline`). На день сужения
основание пусто, и пустое оно — цель, а не отказ.

## check-03 — у ведомой записки есть оболочка

**Находка:** записка `lessons/` или `runbooks/` без `title`, без `category`, с
категорией, не совпадающей с каталогом, или со `status` вне словаря. Словарь
выводится из `obsidian/kacho/CLAUDE.md` (таблица трёх вёдер); нет таблицы — VOID.

## Что доказывают inject-01, inject-02, inject-03

| Проверка | Дефект | Законный близнец | Предпосылка |
|---|---|---|---|
| `check-01` | PEM в архиве, токен GitHub в уроке, учётный литерал в процедуре → код 1 + координата, значение не напечатано | имя без цифр, заглушки → молчание | пустое хранилище → VOID |
| `check-02` | ссылка в никуда из урока → код 1 + цель | три живые формы ссылки; та же ссылка в никуда в архиве → молчание | пустое хранилище → VOID; устаревшее основание → код 1 |
| `check-03` | урок под чужой категорией; `status` вне словаря → код 1 + координата | полная оболочка, витрина; та же поломка в архиве → молчание | нет таблицы словаря → VOID |

Контроли близнецов спрашивают **про свой файл**, а не про чистоту всего дерева.

## Границы

Набор судит **оболочку, связность и учётные литералы**, а не правдивость содержания.
Учётный литерал без цифр (пароль-слово) форма не ловит — это осознанный предел:
предикат по словам краснел бы на именах ресурсов.
