# Рабочие копии и черновики агентов

Здесь заводятся worktree полос, логи прогонов и черновики. Каталог **игнорируется**
git и в поставку не входит.

Почему не `/tmp`: он эфемерен и чистится системой. Работа, лежащая там
незакоммиченной, существует в одном экземпляре и пропадает без следа — это уже
случалось. Здесь она переживает перезагрузку и видна переписи веток.

Убирать за собой обязательно: `git worktree remove <путь>` по окончании полосы.
