# Ускорение потока: упаковка полос, конвейер, схождение документов

Основания: запрос владельца 2026-09-30 «пожем более плотно сгруппировать что бы за 24 часа максимум 45» и «Можем записать паттерн ускорения в рул?»; каскад «таск -> волна -> эпик -> main» (2026-09-26); один круг ревью плюс проверка исполнения, ролей не больше трёх (2026-09-27); критерии рецензентов — в задании исполнителю (2026-09-28). Ускорение берётся из устройства работы и запретов не смягчает (`00-kacho-core.md` ban19-fast-not-skip).

## Инструмент расписания

`scripts/lane-schedule/lane-schedule.py` читает `tasks.md` под-фаз (раздел `## <N>. Полосы`: колонки «исполнитель», «зависит от», «размер» и колонка репозитория с путями; заголовок `### … S<n>` объявляет стадию; в ячейке «зависит от» список ссылок — до первой «;», дальше пояснение, и оно рёбер не даёт — заметка называет отброшенное) и печатает перепись файлов, число полос и пакетов, агент-часы, критический путь с составом, срок при 6/7/8 слотах, минимум слотов до срока, равного пути, и таблицу пакетов (TSV, `--out`).

- Режимы: `--edges A` — рёбра внутри задач; `--edges B --semantic <ведомость>` — плюс смысловые рёбра между под-фазами (TSV из трёх полей: под-фаза, жетон, цель: полосы, чья ячейка «зависит от» несёт жетон, ждут все полосы цели). `--pack guard` — норма; `--pack literal` — для сравнения.
- Исходы: 0 — рассчитано; 1 — отказ (цикл явных рёбер с путём, строка таблицы не той ширины либо без заголовка, нет раздела, повтор id полосы либо под-фазы, строка ведомости не из трёх непустых полей, без полосы-носителя либо с под-фазой не из входа, `--minutes` не ровно S, M, L, вход не читается); 2 — пустой обход (ноль файлов, ноль полос, пустая ведомость), это не «срок 0». Цикл, замкнутый только раскрытием стадии, снимается с заметкой.
- Длительности S/M/L = 15/25/45 мин и 25 мин ревью на пакет — ориентир, не замер: перемерить на новой модели (`--minutes`, `--review`).
- Приёмка — `scripts/lane-schedule/inject.sh`: пример с путём 200 мин, посчитанный руками, цепочка на пределе, `literal` против `guard`, режим B, отказы, и пары «дефект — законный близнец» на каждое решение из перечня `scripts/lane-schedule/mutants.py`; счёт утверждений печатает прогон. `mutants.py` применяет к копии инструмента перечень однофактных порч (граница guard, счёт единиц, ревью, межфазные рёбра, ячейка «зависит от», цепочка и склейка, цикл, код пустого обхода, срок при N слотах, отказы входа, печать итогов) и краснеет, если набор остался зелёным хоть на одной либо фрагмент порчи устарел. Полнота перечня — не утверждение по памяти: он сверен разведочным прогоном всех однофактных порч разобранного дерева (сравнение, and/or, not, условие if, целая константа, max/min, +/−); выжившие там — равносильные исходнику (`EQUIVALENT`, довод у каждой) и отличимые без пробы (`UNHELD`, печатаются каждым прогоном — держатся вниманием). Порчи строковых констант и регулярных выражений разведкой не перебирались. Запускает `scout` по заданию диспетчера и возвращает вывод дословно; правит `tooling-maintainer`, правку принимает `check-verifier`.

## Раздача

fa-a1-schedule-before-dispatch · до раздачи получи расчёт инструментом (пакетов, агент-часы, критический путь, срок при 6/7/8 слотах) и раздавай по его таблице · `scripts/lane-schedule/lane-schedule.py`: код 0 и строка «критический путь: N мин» в возврате `scout` · red: раздача без расчёта; срок назван на глаз
fa-a2-chain-one-agent · подряд зависимые полосы одного исполнителя и репозитория отдай одним пакетом одному агенту; предел 4 единицы (S и M — 1, L — 2) · `scripts/lane-schedule/inject.sh` K2, U1, U2, H1, H2, P1, P2, P3 · red: цепочка одного исполнителя роздана нескольким агентам; пакет больше 4 единиц
fa-a3-merge-only-if-path-holds · склеивай однотипные независимые полосы одного исполнителя и репозитория, включая разные под-фазы, только если склейка не удлиняет критический путь (`--pack guard`) · `scripts/lane-schedule/inject.sh` K1, K3, G1, G2, M1, W1…W6 · red: ранняя полоса ждёт позднюю в одном пакете; путь `literal` длиннее `guard`
fa-a4-semantic-edges-in-graph · внеси смысловые рёбра между под-фазами («X на стенде», «X влита») в ведомость `--semantic` и называй срок режимом B · `scripts/lane-schedule/inject.sh` K4, K5, I1, X1, X2, R1, R6, R6b · red: срок назван режимом A при непустом разделе «Внешние зависимости»; строка ведомости без носителя
fa-a5-stacked-branches · ветку зависимого пакета заводи от головы предшественника; полосы волны своди в ветку волны, её запрос — в ветку эпика, в `main` — один запрос эпика · ЗАВЕСТИ fa-a5-stacked-branches · red: зависимый пакет ветвлён от ствола и ждёт вливания предшественника; второй запрос в `main` при открытом эпике
fa-a6-pipeline-no-barrier · освободился слот — стартуй следующий готовый пакет с наибольшим остатком пути, не жди закрытия волны; сборку и прогон веди партиями по 4–8 готовых пакетов · модель расписания `scripts/lane-schedule/lane-schedule.py` (список готовых по остатку пути), `scripts/lane-schedule/inject.sh` Q1…Q4, Z1, Z4 · red: слот свободен при готовом пакете; «ждём остальных полос волны»
fa-a7-slots-within-budget · держи слотов не больше бюджета машины (агентов одновременно 6–8, тяжёлых сборок 2); срок держит критический путь — ускоряй разрезом искусственных зависимостей, а не агентами сверх пути · строка «слотов до срока = пути» инструмента · red: слотов больше бюджета; агенты добавлены, когда срок уже равен пути
fa-a8-one-review-round · ревью — один круг плюс проверка исполнения, ролей не больше трёх; критерии рецензентов клади в задание исполнителю до начала · ЗАВЕСТИ fa-a8-one-review-round · red: второй круг по роду, известному до раздачи; задание без критериев рецензентов
