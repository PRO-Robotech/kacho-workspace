# git-issues: перепись веток и снятие

Часть правила `git-issues.md`. Механизм — `scripts/branch-audit.sh`; способность упасть
доказана `scripts/branch-audit-inject.sh`.

## Семь признаков вливания

gba-seven-signs · суди вливание семью признаками; решающие — дельта слияния во временной копии, поглощение пофайлово и построчная перепись с вопросом «касался ли ствол этого пути» · scripts/branch-audit.sh · red: вердикт взят из одного признака
gba-merged-flag-lies · не определяй вливание через `git branch --merged`: здесь вливают схлопыванием и через линию · замер: `--merged origin/main` дал 0 при 13 влитых из 63 · red: влитая ветка названа неслитой и снята вместе с работой

## Вид 1. ПЕРЕНОС

gba-transfer-removes-the-source · переносишь работу на свежую базу — снимай исходник в ТОМ ЖЕ заходе и называй это в теле PR-преемника · перепись веток на origin по номеру задачи · red: задача закрыта, PR влит, ветка с её номером жива, потому что head-веткой был другой

## Работа в единственном экземпляре

gba-single-copy-goes-to-origin-first · отправляй на origin либо сдавай PR ветку, которой нет на origin и которая не влита, ДО любой чистки · scripts/branch-audit.sh, код 1 · red: `git branch -D` уничтожил работу без следа и без вопроса
gba-count-branches-not-commits · считай ВЕТКИ, а не коммиты: работа теряется внутри ветки, которая на origin есть · коммитный предикат рядом с переписью веток · red: перепись зелена, а коммит полосы не влит никуда

## Ветка, чью работу вливает НЕ она сама

gba-one-branch-one-subject · держи в ветке один предмет: закрытие PR по первому не является вердиктом по второму · дельта слияния со стволом не пуста при `MERGED`/`CLOSED` · red: ветка снята по статусу PR вместе со вторым предметом
gba-branch-not-busy-before-removal · установи перед снятием, что ветка не занята рабочей копией и что в неё не коммитит соседняя сессия · `git worktree list` и время последнего коммита · red: снятие оборвало живую сессию

## Вердикт «уникальна» имеет срок годности в минуты

gba-census-expires-in-minutes · прогоняй перепись НЕПОСРЕДСТВЕННО перед снятием, а не «сегодня утром» · повторный прогон `scripts/branch-audit.sh` · red: ветка, измеренная как единственный экземпляр, через 35 минут оказалась влита
