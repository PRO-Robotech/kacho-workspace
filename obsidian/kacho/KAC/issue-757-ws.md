# ws#757: свойство куплено вниманием — за 39 проверками восьми наборов не стоит ничего

**Состояние на момент записи**: `to-do`. Задача **открыта**, PR нет
(`gh issue view 757 --repo PRO-Robotech/kacho-workspace --json state` → `OPEN`, 2026-09-22).
Метки: `tech-debt`, `P1`, `size:M`, `area:tooling`, `release:gates`.

## Что и зачем

Проверка, берущая корень дерева из **текущего каталога**, судит дерево, из которого её
**запустили**, а не то, из которого её собрали. Запущенная из чужой копии, она молча оценивает
чужое, а не найдя предмета — выходит **нулём находок**. Ошибка односторонняя и тихая: она
превращает «не смотрел» в «чисто».

Держатель свойства «корень выводится из расположения проверки» есть у **2 файлов одного
набора**. В остальных **восьми** наборах — **39 проверок** — держателя **ноль**, и гейта на это
свойство по всему дереву скриптов нет ни одного (замер полосы, 2026-09-22; число проверок в
наборах там **перечислено**, а не выведено глобом — что само по себе предмет пункта 2 предиката).

Цена уже платилась: этот же класс в тот же день чинили **в шести местах**.

## Соседи — не дубли (из тела задачи)

`#624` — единственность **объявления** резолвера ствола (два кодека одного предмета);
`#732` — тот же род «вердикт по условию, которого не назвали», но в дереве продукта и про
границу обхода. Ни одна не говорит о **способе получения корня** и о покрытии им девяти наборов.

## Предикат снятия (четыре пункта, из тела задачи)

1. проверка, взявшая корень из рабочего каталога, **краснеет в любом** из девяти наборов —
   доказано инъекцией в каждый, с координатой находки;
2. число проверок под обходом **выведено глобом по дереву**, а не перечислено;
3. пара в обе стороны: законный близнец, берущий корень из своего расположения, **молчит**;
4. гейт печатает объём осмотренного и **падает на пустом обходе**.

## DoD (из тела задачи)

- [ ] tree-wide гейт с собственной инъекцией, зовущийся конвейером и хуком отправки;
- [ ] все девять наборов под обходом, счёт наборов и проверок выведен из дерева;
- [ ] инъекция и законный близнец в дереве, оба вывода в теле PR.
