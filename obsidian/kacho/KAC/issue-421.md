# issue-421 — ui: страница с именем чужого поставщика личности снята

**Status:** test — PR [#443](https://github.com/PRO-Robotech/kacho/pull/443).

## Что и зачем

Обе видимые строки с именем стороннего поставщика личности жили на странице списка
пользователей, которую **не рендерит ни один маршрут**: `/iam/users` ведёт в тонкую обёртку
над общей оболочкой списка. Переименовывать было нечего — исход второй из названных в
задаче: снять страницу.

Вместе с ней ушли устаревшая загрузка списка одним запросом на 200 строк и вторая
реализация таблицы пользователей мимо общей оболочки. Страница приглашения, живущая на
собственном маршруте, вынесена в свой каталог: файл с именем снятой страницы был бы
утверждением о дереве, переставшим быть верным.

## Чем держится

Словарь `no-internal-vocabulary-in-user-text` пополнен закрытым перечнем сторонних
поставщиков личности: имя чужого продукта в подписи, подсказке или причине отказа —
находка. Гейт читает только не-тестовые файлы, поэтому файл сквозной пробы, который несёт
этот перечень предметом, в перепись не попадает by construction.

## Что предикат задачи НЕ достигает — и это названо

`git grep -in zitadel` → 0 этим изменением не достигается: четыре форка `api/auth.ts` ведёт
де-форк модулей консоли, а записи в развёртывании — свидетельство о самой замене
поставщика, а не подпись в интерфейсе.

## Побочный предмет

Вместе со снятой страницей с консоли ушло единственное обращение к запрету участия
пользователя. Возможности на экране не было и до снятия — перепись глаголов консоли
сделала её отсутствие видимым (48 → 46) и заведена предметом
[#440](https://github.com/PRO-Robotech/kacho/issues/440), а не оставлена молчанием.
