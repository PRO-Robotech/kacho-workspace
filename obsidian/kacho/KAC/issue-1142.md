# #1142: базовый токен доступа — однострочный секрет с отзывом

**Состояние на момент записи**: задача открыта, метка `status:test`; полоса влита в
накопительную ветку линии (`release/identity-4`), в стволе её на момент записи нет —
2026-08-25.

## Что и зачем

Публичных глаголов выдачи удостоверений в iam два, и **оба** возвращают ключевую
пару, а не токен. Готовый токен доступа в публичном контракте не выдавал никто.

Следствие для арендатора: попросив «токен для доступа к API», он получает материал,
которым обязан **сам** собрать и подписать утверждение по RFC 7523, а затем его
обменять. Для этого нужна библиотека JOSE — барьер, которого у **базового** вида
удостоверения быть не должно: обычный вид — однострочный секрет в заголовке
авторизации.

Второе следствие, наблюдавшееся в продукте: докер-полоса принимала в поле пароля
ключевой материал, потому что иного вида удостоверения у неё не было. Приватная
половина пары переставала быть приватной — её смысл подписывать, а не путешествовать;
плюс многострочный материал непригоден как значение параметра, как переменная
сборочного конвейера и как секрет оркестратора.

**Ключевая пара остаётся и правильна** для своей роли — подпись утверждения,
федерация, долгоживущее доверие. Задача её не отменяет, а **разводит два предмета**,
до сих пор слитых в один.

## Решение

Форма — долгоживущий секрет с отзывом (решение владельца 2026-08-23), выдаваемый
**и машине, и человеку сразу**, одной подфазой:

| ось | значение |
|---|---|
| вид | однострочный секрет: узнаваемый префикс + идентификатор + случайная часть |
| показ | один раз при выдаче, невосстановим |
| хранение | только хеш; сравнение постоянного времени |
| отзыв | по идентификатору токена, действует **на предъявлении** |
| срок | задаётся при выдаче, предел — политикой |
| носители | служебная учётка и человек — одной формой |

Отзыв, действующий на предъявлении, а не только на выдаче, — прямое следствие класса
[[lessons/revocation-that-binds-at-issue-not-at-presentation]]: контроль на выдаче
новых удостоверений не отменяет уже выданного, и окно тогда задаёт срок жизни
удостоверения, а не срок кеша.

Полоса сдана целиком: контракт, словарь видов, форма секрета, хранилище, домен,
use-case, полоса края, полоса докера, каталог прав и сквозной кейс.

**Граница задачи названа в её теле:** приём ключевого материала в поле пароля
докер-полосы снимается **отдельно**, после закрытия этой, — иначе вход в реестр
сломается раньше, чем появится замена. Порядок: ввести → перевести клиентов → снять
приём. Снятие — [[KAC/issue-1143]].

## Чем держится

Локальный прогон полосы: 12 проверок, отказов 0; интеграции — 36 пакетов, отказов 0.

Предикат снятия из тела задачи требует шести утверждений, и решающее из них —
проба **сквозь обе стороны**: отозвали → предъявили → получили отказ. Две пробы по
половине («отзыв записан» и «предъявление проверяется») этот класс не ловят.
