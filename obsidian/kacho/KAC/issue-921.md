# #921 — номер миграции: метка времени вместо номера задачи

## Предмет

Номер выводился из номера задачи. Это решало столкновение слотов — две линии не смотрят на
один последний файл в каталоге. Обратная сторона: задачи берутся **не по возрастанию**,
поэтому задача с номером ниже максимального применённого даёт версию меньше текущей версии
базы. Мигратор такую не применяет и роняет старт; свежая база получает одну схему,
существующая — другую, и расходятся они молча.

Цена была уплачена до заведения задачи: в одной работе клейм строки заменили замком
прохода — приём слабее по существу, выбранный ограничением нумерации.

## Решение

Метка времени заведения `YYYYMMDDHHMMSS`. Сохраняет исходное свойство (номер **выводится**,
а не выбирается) и добавляет монотонность by construction: четырнадцать цифр больше любого
унаследованного шестизначного. Совпадение двух линий до секунды остаётся предметом
проверки уникальности.

Унаследованные **302** номера не переномеровываются — применённое править нельзя (ban #5),
правило действует вперёд.

## Чем держится

Проверка судит только файлы, добавленные относительно ствола, и объявляет себя
беспредметной без ссылки на ствол. Инъекция: старый номер назван координатой, метка времени
в находки не попала.
