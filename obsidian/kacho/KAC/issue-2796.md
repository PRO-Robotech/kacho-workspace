## Что и зачем

Консоль рисует свои экраны входа (приёмка F8), край ведёт вход на `/iam/v1/authorize`.
Эта записка — trail волны как единицы вливания: какие сборки влиты в её ветку, с какими
головами и каким вердиктом. Предмет каждой задачи описан в её записке, а не здесь.

Задачи волны — её sub-issue; перечнем они здесь не выписываются, потому что состав меняется
переносами между волнами:

```sh
gh api repos/PRO-Robotech/kacho/issues/2796/sub_issues --paginate -q '.[] | "#\(.number) \(.state) \(.title)"'
```

## Как вливается

Готовые задачи сводятся в ветку сборки коммитом слияния (`git merge --no-ff`), и конвейер,
рецензенты и приёмка гоняются **один раз** на голову сборки. Возвраты идут по задачам в их
ветки, затем одно повторное сведение и один повторный прогон. Вердикт снимается по прогонам
головы запроса (`gh run list --commit <sha>`). Задачи, влитые в волну, не закрываются: метка
`status:test`, закроет их посадка эпика в `main`.
