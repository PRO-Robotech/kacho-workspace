**Назначение:** trail релизной линии. **Категория:** KAC. **Состояние:** in-progress —
работа сведена, MR #1054 идёт к стволу.
**Чем сверено:** `PRO-Robotech/kacho` @ `origin/release/iam-closeout`, 104 коммита над
стволом; локальный прогон 11 проверок / 0 отказов.

## Что и зачем

Служба личности накопила долг, у которого была общая черта: **объявленное не доезжало до
исполнителя**. Конфигурация существовала, но её никто не монтировал; ключ обёртки
перевыпускался на каждом подъёме стенда; адреса потоков вели туда, где их никто не
обслуживает; полоса обратных вызовов исполнялась и отвергалась.

Линия закрывает это одним MR — конвейер тратится один раз.

## Чему научила сборка волны

**Три столкновения полос**, каждое невидимо ни для git, ни для отдельных прогонов — обе
работы верны у себя, ломается только сведённое дерево:

1. **имена** — две полосы завели байт-идентичного помощника в одном пакете; файлы разные,
   конфликта нет, каждая ветка компилируется;
2. **ожидания** — одна написала гейт на литералы, другая параметризовала шаблон; гейт не
   смолчал на непрочитанном и назвал оба исхода;
3. **раскладка** — починка «почтовый процесс не читает то, что монтирует» сделана на
   прежней раскладке, а новая повторила дефект в себе.

**Вывод для будущих волн:** волна не сдана, пока её ветки не собраны вместе и по собранному
не прогнан полный локальный набор. Зелёное каждой ветки по отдельности о совместимости не
говорит ничего.

- #1081 — предикат меню действий открыт по умолчанию.

контроль пробы выполнялся пустой таблицей, из-за чего все четыре отрицания кейса были
