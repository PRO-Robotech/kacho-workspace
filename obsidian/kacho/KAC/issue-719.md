# #719: координаты записок пережили переезд предмета

**Type**: fix

**Состояние на момент записи**: test — правка лежит на ветке `issue-719`, в `main` не
влита — 2026-09-20.

## Что и зачем

Задача называла 7 координат в трёх записках. Перепись тем же предикатом по всему дереву
хранилища дала **114 неразрешимых координат в 78 записках** — то есть предмет задачи был
не в трёх записках, а в классе. Чинился класс.

Причина у класса одна и она известна: предмет уезжал, а координата оставалась.

| Причина | Чем подтверждена | Координат |
|---|---|---|
| контракты и пакеты службы доступа ушли в её репозиторий | kacho `a10bfd208d4` «Kaname: служба доступа становится самостоятельным продуктом (#2118)», 2026-09-08 | **84** |
| библиотеки фундамента уехали из `pkg/` в свой репозиторий | каталоги `project/corelib/*` против прежних `pkg/*` | **15** |
| форма и глагол операции — под имя фундамента | kacho `bdaedfd5aaa` (#2659), 2026-09-15 | **6** |
| подписка на изменения — под имя фундамента | kacho `edc98869b70` (#2650), 2026-09-15 | **3** |
| предмет снят целиком, преемника нет | `29ad7b78d80` (шов датаплейна, 2026-08-16), `e818be695c4` (#671, `access.proto`, 2026-08-18), снятие семейства проверок формы | **4** |
| прочее: каталог снятого пакета, переименование пакета vpc | поштучно | **2** |

Сумма — 114. Внутри первой строки **16** координат — не переезд, а изъятие: службы
`ConditionsService`, `FederationService`, `FederationExchangeService`,
`OrganizationService`, `TrustPolicyService`, `CAEPSubscriberService`,
`InternalAuthorizeService`, `InternalLimitService` и перечисление `BuiltinCondition`
не заведены ни в одном дереве, часть из них не была заведена никогда.

## Исход по каждой координате — из трёх, «оставить» среди них нет

**Починено утверждение** — **96**: координата переписана в разрешимую форму. Из них 13 —
в историческую (`<repo>@<sha>:<путь>`): утверждение было замером прошлого, и ревизия
возвращает ему проверяемость вместо того, чтобы выдавать его за сегодняшний день.

**Утверждение снято** — **18**: предмета нет ни в одном дереве, путь заменён именем файла
или службы. Число получено машинно: координат в хранилище стало 222 → 204, и разница —
ровно те пути, которые перестали быть путями.

**Починено дерево** — **0**. Ни одна находка не оказалась случаем «прав документ, неправо
дерево»: каждый переезд подтверждён коммитом, каждое изъятие — записью в композиции или
коммитом снятия. Исход назван нулём, а не умолчан.

## Форма координаты — решение, ради которого волна и делалась

Голый путь читается как путь в дереве платформы. Поэтому `proto/kaname/...` без префикса
— координата **мёртвая**, даже когда такой файл у службы есть: она показывает в дерево,
где его нет. Четыре формы и их проверка сведены в [[CLAUDE|конвенции хранилища]];
исторические утверждения адресуются ревизией (`<repo>@<sha>:<путь>`), и тогда замер
прошлого остаётся проверяемым, а не превращается в ложь о сегодняшнем дереве.

## Предикат снятия — знает все формы записи

Предикат, знающий одну форму, недобирает молча: первая его редакция резолвила голый путь
по трём деревьям подряд и объявляла живой координату `proto/kaname/...` в записке
платформы (недобор 86 против 114); вторая не знала поля оболочки `proto_file:`/`path:`
(недобор ещё 43). Действующая редакция знает **все четыре** формы, печатает объём
осмотренного и падает на пустом обходе.

```python
# запускать из корня воркспейса: python3 <файл> obsidian/kacho
# коды: 0 — чисто · 1 — есть неразрешимые · 2 — пустой обход (предикат недействителен)
import os, re, subprocess, sys
WS = os.getcwd()
VAULT = sys.argv[1] if len(sys.argv) > 1 else "obsidian/kacho"
TREES = ("kacho", "kaname", "corelib")
GITC  = re.compile(r'git\s+-C\s+(?:[\w./-]*/)?([a-z][a-z0-9-]*)\b')
HIST  = re.compile(r'\b([a-z][a-z0-9-]*)@([0-9a-f]{7,40}\^?):((?:proto|api)/[A-Za-z0-9_./-]*\.proto)')
REV   = re.compile(r'\b((?:origin/)?[A-Za-z0-9_./-]+):(proto/[A-Za-z0-9_./-]*\.proto)')
PATH  = re.compile(r'(?:project/[a-z0-9-]+/)?proto/[A-Za-z0-9_./-]*\.proto')
FIELD = re.compile(r'^\s*(?:proto_file|proto):\s*"?((?:project/[a-z0-9-]+/)?[A-Za-z0-9_][A-Za-z0-9_./-]*\.proto)"?\s*$')
DIRF  = re.compile(r'^\s*path:\s*"?((?:project/[a-z0-9-]+/)?[A-Za-z0-9_][A-Za-z0-9_./-]*)"?\s*$')

def live(c, home="kacho"):
    p = c if c.startswith("project/") else os.path.join("project", home, c)
    return os.path.exists(os.path.join(WS, p))

def at_rev(repo, rev, path):
    return subprocess.run(["git", "-C", os.path.join(WS, "project", repo),
                           "cat-file", "-e", "%s:%s" % (rev, path)],
                          capture_output=True).returncode == 0

notes = coords = dead = carry = bad_notes = hist = 0
for root, _, files in os.walk(VAULT):
    for name in sorted(f for f in files if f.endswith(".md")):
        p = os.path.join(root, name); notes += 1; hits = bad = 0
        for n, line in enumerate(open(p, encoding="utf-8", errors="replace"), 1):
            gm = GITC.search(line)
            home = gm.group(1) if gm and gm.group(1) in TREES else "kacho"
            spans, found = [], []
            for m in HIST.finditer(line):
                spans.append(m.span()); found.append((m.group(0), ("hist", m.group(1), m.group(2), m.group(3))))
            if gm:
                for m in REV.finditer(line):
                    if any(s <= m.start() < e for s, e in spans): continue
                    spans.append(m.span()); found.append((m.group(0), ("hist", home, m.group(1), m.group(2))))
            for m in PATH.finditer(line):
                if any(s <= m.start() < e for s, e in spans): continue
                found.append((m.group(0), ("live", m.group(0))))
            if not found:
                dm, fm = DIRF.match(line), FIELD.match(line)
                if dm:
                    found = [(x.strip(), ("live", x.strip())) for x in dm.group(1).split(",")]
                elif fm:
                    v = fm.group(1)
                    found = [(v, ("live", v if v.startswith(("project/", "proto/")) else "proto/" + v))]
            for shown, c in found:
                hits += 1; coords += 1
                ok = at_rev(c[1], c[2], c[3]) if c[0] == "hist" else live(c[1], home)
                if c[0] == "hist": hist += 1
                if not ok:
                    dead += 1; bad = 1
                    print("МЁРТВАЯ  %s:%d  %s" % (os.path.relpath(p, VAULT), n, shown))
        carry += bool(hits); bad_notes += bad
print("---")
print("осмотрено записок: %d; из них несут координату: %d" % (notes, carry))
print("координат проверено: %d (исторических, по ревизии: %d)" % (coords, hist))
print("неразрешимых: %d в %d записках" % (dead, bad_notes))
sys.exit(2 if coords == 0 else (1 if dead else 0))
```

**Исход прогона.** До правки — `неразрешимых: 114 в 78 записках` при 222 координатах в
149 записках из 1231 осмотренной. После — `неразрешимых: 0 в 0 записках` при 204
координатах в 139 записках из 1231 осмотренной. Координат стало меньше на 18: ровно
столько путей перестали быть путями, потому что предмета нет (исход «утверждение снято»).

**Контроль в обе стороны прогнан**: подсаженная в записку строка вида
`proto/<домен>/<файл>.proto`, которой в дереве нет, находится — прогон даёт ровно одну
находку и код 1; пустой каталог даёт код 2, а не зелёное. Сама подсадка здесь написана
образцом, а не путём: мёртвая координата в этой записке была бы находкой собственного
предиката (и была ею, пока строку не переписали).

## Чего эта волна НЕ закрыла — названо числом, а не умолчано

Предикат судит координаты **файлов контракта** и машинно проверяемые поля оболочки
(`proto_file:`, `proto:`, `path:`). Прозаические ссылки на файлы кода внутри тела записок
(`services/**`, `gateway/**`, `pkg/**`, `internal/**`, `deploy/**`) он не судит. Их объём
назван числом, а не умолчан: по дереву хранилища таких ссылок **595**, и **326 из них в
166 записках** не резолвятся ни в одном из трёх деревьев (замер 2026-09-20, предикат
пробует все три дерева подряд — то есть это **нижняя** оценка, строгая даст больше).

Класс тот же и он остаётся открытым. Волной вслепую он не чинится: у прозаической ссылки
чаще есть ревизия и контекст, и решение «живая или историческая» принимается поштучно —
ровно так, как в этой задаче принималось для 22 журналов.
