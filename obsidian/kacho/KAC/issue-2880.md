# kacho#2880: одновременные прогоны ci-local одной копии делят кэш и журналы

## Что и зачем

**Признак.** 2026-09-26 две отправки из одной копии продукта шли одновременно, и оба прогона
хука отправки писали журналы в один каталог под временным разделом: на `main` @ `1d42a6728bf`
каталог выводится только из пути копии. Журналы по прогону уже дала [[KAC/issue-2852|#2852]] на
ветке эпика `2564` (координата, не живая ссылка) @ `7190c3e5274` — у каждого прогона свой
каталог `run-*`. Но у одновременных прогонов одной копии общим остаётся **кэш копии** (бинарники
`protoc`, `gosec`, `tofu`, плагины, кэш линтера), а уборка старых прогонов снимает каталоги
сверх пяти, не проверяя, жив ли их прогон. Каталог по умолчанию лежит вне копии.

Учёт снятия веток в тот заход разошёлся — 2 снятых против 3 ушедших с origin. Причина **не** в
общем журнале, а во втором заходе снятия: третью ветку снял он, а первый записал «уже снята».
Это отдельный факт, на предмет правки не влияет.

Класс — вердикт становится свойством соседства. Предшественники закрыты: kacho#677 (каталог на
машину), kacho#679 (общий рабочий каталог), [[KAC/issue-2852|#2852]] (повтор в той же копии);
kacho#2625 и #2642 — тот же класс в службе доступа, по телу задачи. Проверка на дубли — в теле
задачи, дублей нет.

**Предмет.** Журналы и рабочие файлы прогона хука и `ci-local.sh` лежат в каталоге своего
прогона, внутри своей копии (например, в её каталоге git). Одновременные прогоны не пишут ни в
один общий путь.

## DoD

Из тела задачи, раздел «ПРЕДИКАТ» (перечислено как есть):

- проба: два прогона `ci-local.sh` из одной копии запущены одновременно — пути, в которые пишет
  каждый, не пересекаются; исключение одно — кэш сборки go, он рассчитан на параллельных
  писателей; проба красная на `2564` @ `7190c3e5274` и зелёная после правки;
- по умолчанию журналы и кэш лежат внутри копии, а не во временном разделе; прогон печатает оба
  пути;
- уборка не снимает каталог живого прогона: шесть прогонов одной копии, старший ещё идёт, его
  каталог цел;
- близнец: при заданном `CI_LOCAL_WORK` всё лежит в названном каталоге, как после #2852.

DoD — предикат выполнен, пробы красные до правки и зелёные после. Артефакт — PR с `Closes`
этой задачи и вывод проб по каждому пункту.
