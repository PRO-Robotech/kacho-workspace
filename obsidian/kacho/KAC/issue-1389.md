# #1389: клиентская документация отрицает поставленную подписку

Закрытие эпика [#1016](https://github.com/PRO-Robotech/kacho/issues/1016) «единый поток изменений ресурсов». Линия работ — [[KAC/watch-unified-change-stream-2026-08]].

Найдена **имитацией клиента** (требование владельца №18, `00-kacho-core.md`): четыре прогона с пустым контекстом, каждый видит только то, что доступно клиенту, — документацию, консоль, контракты, профили развёртывания. Две имитации — «продакт» и «разработчик» — пришли к этому порознь,
каждая своим путём.

## Предмет

Клиентская документация отрицает построенное **четырьмя страницами**: быстрый старт края,
обзор API края, архитектура compute, обзор API storage. Особо: **compute объявляет «не
планируется», будучи назначенным первым владельцем журнала** в том же дереве.

Цена названа имитацией «разработчик» прямо: около трёх часов ушло на то, чтобы **не
поверить четырём документам** и полезть в контракты. Клиент, который читает и верит,
останавливается на четвёртом шаге из двенадцати и строит на опросе — решение, которое
переделывают месяцами.

Это DoD-7 эпика, но **предмет шире правила**: `api-conventions.md` читают разработчики
продукта, а эти страницы читает клиент. Правило приведено в соответствие отдельно (см.
раздел линии); страницы — здесь.

## Предикат снятия

1. перепись утверждений вида «такого механизма нет» по клиентской документации даёт ноль
   противоречащих дереву;
2. каждое переписанное место называет **новое** состояние, а не молча удаляет прежнее:
   опрос остаётся законным и задокументированным путём, подписка — вторым;
3. `api-conventions.md` §«Watch RPC не существует» переписан по факту;
4. гейт: утверждение «механизма нет» в клиентской документации краснеет, когда механизм
   в дереве есть.

**Предикат перемерить.** Число, названное имитацией (семнадцать утверждений в двадцати
одном файле), в задаче помечено как не перепроверявшееся — оно ориентир, а не факт.

## Состояние

Открыта, `status:test`. Роль — `kacho-docs-writer`. Правило воркспейса
(`api-conventions.md`) закрыто волной A, страницы продукта — нет.
