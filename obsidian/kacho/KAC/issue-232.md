# #232: список групп целей nlb не заполнял targets

**Type**: fix

**Состояние на момент записи**: test — влито в `issue-232`, ждёт вердикта PR #324 в
`release/tech-debt-sweep` — 2026-08-14.

**Где ведётся**: `PRO-Robotech/kacho` — `services/nlb/internal/repo`, `proto/kacho/cloud/loadbalancer`,
`services/nlb/docs`.

## Что и зачем

Одиночное чтение группы целей отдавало цели, списочное — пустой массив на тех же
группах. Message контракта у обоих один, поэтому пустой массив читается вызывающим
как **факт о ресурсе** («целей нет»), а не как «это чтение поле не заполняет».
Различить два смысла на проводе нечем; клиент, ведущий состояние из списка,
прочитал бы ответ как «все цели удалены».

Из трёх законных исходов (`api-conventions.md` §«Пустое значение обязано означать
пусто», подраздел B) выбран первый — заполнять: комментарий самого контракта уже
обещал заполнение обоими чтениями, то есть расхождение было между контрактом и
кодом, а не между двумя защитимыми проектными решениями.

Цена названа и ограничена: одна дополнительная выборка на страницу; потолок целей
остаётся потолком **на группу** (нумерация внутри партиции, не общий `LIMIT` —
иначе первая большая группа съедала бы квоту соседей и дефект вернулся бы с другой
стороны); цели читаются **после** усечения страницы.

Заодно закрыт подраздел A того же правила: у повторяющегося поля обязан быть
объявлен порядок. Он объявлен **набором** — порядок не значим и не сохраняется,
сверять состав надо по элементам, не по индексам. Причина: у целей нет
позиционной семантики (долю трафика задаёт вес), а сортировка по времени
создания на строках одной транзакции разрешается случайным идентификатором.

## Чем держится

`TestTG_ListProjectionMatchesGet` — читает один и тот же ресурс **обоими** путями и
требует совпадения по объявленным полям; рядом соседняя группа без целей, чтобы
«подгрузил, но приписал не той группе» отличалось от «не подгрузил вовсе».
`TestTG_ListTargetsPerGroupCapped` — три группы по четыре цели, квота не общая.

## Радиус класса

Предикат «`Get` подгружает детей, `List` — нет» по 28 файлам `*_repo.go` всех
сервисов: **1** расхождение до правки, **0** после. Контроль прогонялся в обе
стороны (на состоянии базовой ветки предикат называет ровно ту координату).
