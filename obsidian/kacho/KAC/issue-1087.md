# #1087: домен описывается манифестом

## Что и зачем

Клиент, поставивший iam в своё облако, пишет YAML и получает работающие права
на СВОИ ресурсы. Сегодня невозможно: каталог типов зашит в Go, и незнакомый
модуль отвергается на пути запроса. Это блокатор №1 выноса iam
(PRO-Robotech/kacho-workspace#382 — записки нет, эпик заведён сегодня).

Эпик — про **входную сторону** (схема, генераторы, проверки); Go-сторона —
#1027. Независимы по файлам, сходятся на одном предикате: «манифест применён,
права работают».

## Артефакты проработки

Форма и её обоснование — [[docs/module-manifest-dcl]].
Урок про снятые поля — [[lessons/manifest-field-without-a-reader]].

**Доказательная база — `docs/manifest-dcl/`** этого репозитория: манифест vpc
целиком, JSON Schema раздела `seed`, генераторы, три набора инъекций и снимки
живого состояния, позволяющие повторить замер без стенда.

Главное: порождённые из манифеста блоки модели **побайтово** равны загруженным
в iam — 5932 байта, md5 `17409a0052ae00fd5c0fc6812e0bc751`.

| ось | итог |
|---|---|
| записи каталога прав vpc | 95 / 95, дублей 0 |
| действующие системные роли vpc | 18 / 18 воспроизводимы |
| операции двух публичных API | 508 / 508 |
| инъекций: валидатор · схема · эмулятор | 38 · 31 · 9 |

## Затронутые сущности vault

- [[iam-access-binding]] — форма выдачи взята дословно у
  `CreateAccessBinding`: `subjects[]` 1..32, `scopeType`/`scopeId`, `target`
  обязателен
- [[iam-role]] — `grants` манифеста изоморфен `Rule` в
  `RoleService.Create`, значит роли уезжают через существующий API
- [[vpc-addresspool]] — привязка пула к сети недостижима by
  construction (#1129), после снятия прав в vpc станет 93 вместо 95
- [[lessons/manifest-field-without-a-reader]] — семь полей схемы заведены и
  сняты как не имеющие читателя

## Развилка, держащая две подзадачи

Ветка **A** (доказана здесь): манифест порождает блоки типов, модель растёт с
каждым доменом. Ветка **B** (#1029): модульные типы не рендерятся вовсе, один
параметрический тип. Взаимоисключающи по тому, что попадает в текст модели;
ошибка направления не правится — работа выбрасывается. Решение — #1104.

## Урок, который дороже самой схемы

Из схемы снято **семь полей**, и все семь были моими: `at`, `in`, `openTo`,
`declaredBy`, `assignableAt`, `clusterOnly`, `catalog`. Каждое выглядело
осмысленным ровно до вопроса «кто это прочитает». Схема писалась как лекарство
от «принято и проигнорировано» — и воспроизвела этот класс семь раз внутри
себя.

**Поле заводится, только когда назван его читатель** — код, который смотрит,
или проверка, которая падает. Комментарий читателем не является.
