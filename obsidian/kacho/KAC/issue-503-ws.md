# ws#503: доказательство падучести prove.py не запускалось вовсе

Найдено по дороге, при попытке проверить собственную работу названным инструментом.

`selftest/inject.py` падал `NameError: SELF_FAILURE_MARK` — **после** контрольного прогона
(≈20 с) и **до** первой инъекции. То есть с посадки #501 у `selftest/prove.py` не было
доказательства падучести, а перепись агрегата релиза «инъекций с контролем 38 · доказано
38» описывала ревизию, которой уже нет (сегодня объявлено **42**).

## Что произошло

Переход к ведомости `DERIVED_MARKERS` и общему раскрытию `expand_markers` оставил в дереве
прежнее, одиночное раскрытие; оба его имени при этом исчезли. Ветвь мёртвая — её работу
целиком делает `expand_markers`, включая случай «раскрывать нечего».

## Пара RED→GREEN

```
до    : NameError: name 'SELF_FAILURE_MARK' is not defined · код 1 · доказано 0
после : контроль зелен (20 с) · инъекции доказаны · код 0
```

Правка внесена **в чужой полосе** как блокер собственной работы (`multi-agent-flow.md`
§«Находка по дороге», единственное исключение): без неё инструмент, названный в задании
средством проверки, не запускается. Остаток — механизм — заведён этой задачей.
