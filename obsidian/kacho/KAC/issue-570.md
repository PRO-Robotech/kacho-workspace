# Ядро волны — три файла, свод читает один ревьюер

## Что и зачем

`.claude/rules/` читается Claude Code **автоматически и целиком**, независимо от
`@import`. Значит цена регламента умножается на ширину волны: 248 600 × 8 = 1 988 800
токенов преамбулы. Каталог разделён на **ядро** (`.claude/rules/`, читают все) и
**свод** (`.claude/rulebook/`, читает по требованию тот, кому он нужен).

## Что решил ЗАМЕР, а не вкус

Три моих предложения снять цену опровергнуты собственным инструментом: вынос правил из
окна · перестановка порядка · контракт полосы. Дешёвая полоса теряет **ровно 2
требования из 19**; ревьюер со сводом возвращает **ровно 2**. Схема владельца выиграла.

| посадка | общие 4 предмета | своя выборка |
|---|---|---|
| `base` — 16 правил в окне каждого | 17/19 = 89 % | 29/34 = 85 % |
| **`review`** — лёгкая полоса + ревьюер со сводом | **17/19 = 89 %** | **22/24 = 92 %** |
| `lane` — правило в задании | 15/19 = 79 % | 24/34 = 71 % |
| `pact` — контракт полосы | 14/19 = 74 % | 18/29 = 62 % |

Инструмент — `scripts/compliance/`: 8 предметов × 39 машинных предикатов по
произведённым артефактам. Он **не гейт**: прогон посадки — 40–80 минут и ≈2 млн токенов,
поэтому зовётся руками (`measure.sh`), а не хуком отправки.

## Размер полосы — тоже замер

Предмет из четырёх слоёв не закрылся ни разу при пределе 1200 с в трёх посадках; при
2400 с закрылся за **2268 с** с 5/5 по проверкам. Одно-слойный — за 752 с. Вывод по
заранее объявленной таблице решений: **предел был занижен** (≈15 мин объявлено против 38
фактических), резать предмет по слоям не требуется.

## Чем держится

Новый набор `scripts/rules-gate/` — три проверки: ядро не растёт · при переносе ничего не
потеряно · манифест покрывает свод. Каждая печатает объём осмотренного, падает на пустом
обходе и доказана инъекцией в обе стороны (`inject.sh` + три части).

Двух дефектов гейтов, найденных противником, стоит помнить: `find -type f` **не видит
симлинков вовсе** — живая ссылка `rules/testing.md → ../rulebook/testing.md` тянула 1326
строк в ядро при вердикте «прочитано файлов ядра 3 … лишних 0»; и координата, перенесённая
на свою строку с точкой на конце, читалась как объявление.

## Остаток, названный числом

Требование «число сопровождается предикатом» не выполнено ни в одной из трёх посадок
(0/3). Три подхода к гейту построены и **отвергнуты** противником по доле ложных: 25.6 %
при подъёме 1.00× над случаем · 12.8 % · ≈40 %. Ни один не поставлен; предикат пересмотра
— ≤5 % ложных при охвате не уже блочного.
