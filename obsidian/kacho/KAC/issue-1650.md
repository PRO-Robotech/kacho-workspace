# #1650: непокрытой была не одна форма вызова, а обе

Часть эпика [#1016](https://github.com/PRO-Robotech/kacho/issues/1016). Линия —
[[KAC/watch-unified-change-stream-2026-08]]. Остаток [[KAC/issue-1637]]: там снята первая
половина предусловия (накат доказан, у доказательства есть производитель), это — вторая.

## Посылка задачи опровергнута, и в неожиданную сторону

Задача называла непокрытой **одну** форму вызова — ту, которой манифест зовёт один сервис.
Замер показал: непокрыты были **обе**. Форму с явным адресом базы не пишет **ни один**
манифест и **ни один** рецепт сборки — все семь берут адрес из конфигурации. То есть
доказательство гоняло форму, которой в дереве не зовут **нигде**.

Это сильнее исходной находки: покрытие выглядело частичным, а было **не тем**.

## Формы ВЫВОДЯТСЯ, а не выписываются

Перечень форм собирается обходом манифестов — иначе он стал бы второй точкой правки того
самого класса, который эта линия закрывала весь день. Перепись: манифестов прочитано **152**,
точек наката **7**, форма выведена для **7**; накат доказан **7/7** в каждой из двух форм.

## Служба объявляется ТРЕМЯ способами, а не одним

Первый RED звучал «форма выведена для 6»: развёртывание одного сервиса объявлено чартом
зонта, а не своим каталогом. Третий способ — ключ подчарта в наложении значений —
обнаружился уже отказом разбора.

Урок для всякого обхода манифестов: **способов объявить службу больше, чем кажется**, и
недостача видна только как «на один меньше», без указания, какого именно.
