# kaname#429: голова ветки эпика без образа — связку линии не выкатить

## Что и зачем

**Признак.** В `.github/workflows/docker-build.yml` службы (одинаково на ветке эпика `357` @
`fc9f5aff` и на `main` @ `cbbac984`; `357` — координата, не живая ссылка) событие `push` — только
`main` и метки `v*`; `pull_request` в `main` и `[0-9]+` собирает, но не публикует;
`workflow_dispatch` публикует тег `<ветка>-<sha8>`. По замеру реестра в теле задачи
(2026-09-26) тегов с `357` и с головой `fc9f5aff` нет, хотя для веток волн путь dispatch дал
теги. Волна-2 [[KAC/issue-358-kaname|#358]] влита в `357` запросом #422, образа у неё нет.

Зонт платформы на ветке эпика PRO-Robotech/kacho `2564` @ `7190c3e527` пинит образ службы
ревизии ствола `main-16b5cade` (`deploy/helm/umbrella/values.yaml:126`); сверх этого пина в
`357` — 427 коммитов по `git rev-list --count 16b5cade..fc9f5aff` (замер тела задачи; повторён
мной 2026-09-26 на той же голове — 427).
Следствие: выкатка линии 2026-09-26 поднялась со службой ствола, и волна-2 службы в связке с
линией платформы не исполнялась ни на одном стенде.

**Предмет.** У головы ветки эпика есть опубликованный образ без ручного шага, найденного
случаем. Два исхода, выбор с доводом — в задаче:

- (а) `push` на ветки линии `[0-9]+` публикует `<ветка>-<sha8>`;
- (б) публикация dispatch — названный шаг закрытия волны с артефактом (тег в комментарии волны).

## DoD

Из тела задачи, раздел «ПРЕДИКАТ» (перечислено как есть):

1. в реестре есть тег `357-<sha8 головы 357>`; ревизия, прочитанная из файла в образе, равна
   голове;
2. следующее вливание волны в `357` оставляет опубликованный образ: при (а) — прогоном по
   `push`, при (б) — шагом, названным в теле эпика; ссылка на прогон;
3. стенд линии платформы, закреплённый на этот тег слоем стенда, поднимается;
   `stand-provenance.sh` называет ревизию `357` — это артефакт для PRO-Robotech/kacho#2871.

Артефакт — PR с `Closes` этой задачи либо прогон dispatch и запись шага; тег образа и вывод
провенанса — комментарием. Каталоги при исходе (б) — ещё и тело эпика kaname#357.
