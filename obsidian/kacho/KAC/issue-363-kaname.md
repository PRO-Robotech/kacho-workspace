# kaname#363: двухрежимный переключатель посадки own/external не снят

**Состояние на момент записи**: `to-do` — 2026-09-26. Задача **открыта**, метки: `P2`, `size:L`, `area:iam`, `release:identity-own`; родитель — волна-4 kaname#367. Работы по ней нет. Несёт сторону службы доступа из предиката закрытой задачи фундамента [[KAC/issue-30-corelib|corelib#30]].

## Что и зачем

Посадку службы выбирает ключ с двумя значениями, `own` и `external`. После снятия чужих служб
личности значение `external` не описывает ничего, что можно поднять, и у службы остаётся одна
посадка: уходят ключ, ветви по нему в корне, требования старта полосы `external`, накладки
профилей и обработчики хуков поставщика.

Фундамент снял значение `external` со словаря посадки (corelib#30, волна-4 corelib#29), оставив
имя устаревшим псевдонимом линии v1.x. Предикат corelib#30 требует, чтобы читателей этого имени
не было и у потребителей; сторону службы доступа — по комментарию закрытия corelib#30 одна
строка — ведёт эта задача, новой под неё не заводилось. Пин фундамента поднимает kaname#424.

## DoD

Из тела задачи (перечислено как есть): поиск имени значения `external` и ключа посадки в
дереве службы — 0; старт службы не читает ключа посадки; рендер каждого профиля даёт одну
полосу входа. Порядок — последней в волне, после задач, снимающих ветви `external` по своим
предметам.
