## Что и зачем

Полная продуктовая документация control-plane сервиса kacho-vpc, выполненная **по образцу
`PRO-Robotech/sgroups-docs`** (Docusaurus 3.10). Описывает весь продукт: ресурсы, API, архитектуру,
IPAM, авторизацию, деплой. Живёт в `kacho-vpc/docs-site/` (изолированно от внутренних
`docs/architecture/*.md`). `npm run build` зелёный (SSG OK, 21 страница отрендерена).

## Структура (21 страница)

- `intro` — обзор (mermaid-архитектура, доменная модель 9 ресурсов, стек).
- `architecture/` — overview · data-model (ER) · operations (LRO) · ipam · authz.
- `api/` — overview · operations + per-resource: Network/Subnet/Address/RouteTable/SecurityGroup/
  Gateway/PrivateEndpoint/NetworkInterface/AddressPool.
- `install/` — deploy · configuration.
- `advanced/` — observability · known-divergences.

Shared: компоненты `ApiOperation`/`Restrictions`/`Codes`/`StatusTable` + DRY-константы
(dictionary/types/restrictions/codes).

## Как сделано

Фундамент (scaffold Docusaurus + компоненты + константы + intro + эталон `api/network.mdx`) — вручную.
Остальные 19 страниц — **параллельным workflow** (19 агентов, читали proto + CLAUDE.md). Фикс MDX-готч
(экранирование `_`/`*` и `{...}` внутри `<code>`, не трогая `{TYPES.x}`-выражения) → build green.

## Источники истины

- `kacho-vpc/CLAUDE.md` — ресурсная модель, RPC, IPAM, authz, error-тексты.
- `kacho-proto/proto/kacho/cloud/vpc/v1/*.proto` — контракт API.
- `kacho-vpc/docs/architecture/` — data-flows, conventions, ER.
