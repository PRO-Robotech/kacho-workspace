# #1110: генераторы каталога прав и таблицы маршрутов вне монорепо

## Что и зачем

Последний открытый блокер вехи M11 ([[KAC/issue-1111]]). Каталог прав и таблица маршрутов
**порождаются** генераторами, и вопрос задачи был: собираются ли они без полного дерева монорепо.

## Исход

Закрыта 2026-09-13. Все четыре пункта действующего предиката выполняются прогонами:

| п. | состояние | предикат |
|---|---|---|
| 1–2 | каталог и таблица из двух частей побайтово равны сборке из общего дерева | `gateway/scripts/check-catalog-splice.sh` — 7 утверждений, 0 находок |
| 3 | гейт склейки существует и способен упасть — **опровергает тело задачи** | появился вливанием #2598, провязка залочена пробой |
| 4 | манифесты доменов не называют держателей внутри снятого каталога службы | держателей 31 → 23, находок 26 → 0 |
| сверх | генераторы собраны из кэша модулей вне всякого чекаута, `GOPROXY=off` | код 0 каждый |

Два числа тела опровергнуты расхождением **единиц счёта**, а не ошибкой: импортёров словаря
разметки 67 (не 65), а канон модели прав *называют* 28 файлов, тогда как *открывают* 13.

## Затронутые сущности vault

- [[KAC/issue-1111]] — веха M11, разблокирована этим закрытием
- [[KAC/issue-2616]] — переезд контрактов службы, вынесенный из развилки этой задачи

## Остаток

Межрепозиторная половина пункта 4 — #2613. Выбор дома контрактов — [[KAC/issue-2616]] по решению
владельца. Стенд не поднимался: вердикта о поведении на кластере нет.
