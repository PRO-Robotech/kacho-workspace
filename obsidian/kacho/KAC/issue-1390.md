# #1390: клиентской страницы подписки нет — вызов собирается из инженерных документов

Закрытие эпика [#1016](https://github.com/PRO-Robotech/kacho/issues/1016) «единый поток изменений ресурсов». Линия работ — [[KAC/watch-unified-change-stream-2026-08]].

Найдена **имитацией клиента** (требование владельца №18, `00-kacho-core.md`): четыре прогона с пустым контекстом, каждый видит только то, что доступно клиенту, — документацию, консоль, контракты, профили развёртывания. Направления «разработчик» и «продакт», независимо.

## Предмет

Имитация «разработчик» получила поручение «сними опрос, у платформы есть подписка» и
прошла путь до конца. **Всё, что нужно для вызова, нашлось вне клиентской документации**:
адрес ручки — в инженерном документе края (каталог объявлен не входящим в сайт); перечень
параметров — одной строкой прозы без значений; словари владельцев и видов — выведены из
ключей чарта и из пробы; форма передачи повторяющегося поля **не сказана нигде**. Ручки
нет и в справочной таблице REST-префиксов — штатный способ обнаружения её не находит.

**Самое существенное:** единственный пример запроса во всём продукте лежит в артефакте,
**который не может покраснеть** — его каталог выведен из исполняемого набора. За
актуальность формы запроса не отвечает никто.

Отдельно: контракт объявляет глагол **внутренним** и о проекции наружу не упоминает.
Клиент, читающий один контракт, обязан заключить «не для меня» — и будет прав, пока не
найдёт инженерный документ, которого ему не показывают.

## Предикат снятия

1. в клиентской документации есть страница «Подписка на изменения»: адрес, таблица
   параметров с допустимыми значениями, словари владельцев и видов, пример кадра
   открытия, пример возобновления, поведение при обрыве;
2. ручка стоит в справочной таблице REST-префиксов;
3. **форма повторяющихся параметров названа явно** — сегодня её нельзя вывести ниоткуда;
4. пример запроса **исполняется** чем-то, что краснеет при расхождении;
5. контракт называет проекцию наружу.

## Цена, названная имитацией

Встраивание — полтора-два дня при включённой возможности; **одна клиентская страница
сократила бы это вдвое**.
