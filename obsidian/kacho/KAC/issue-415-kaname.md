# kaname#415: коллекции предмета платформы без производителя в конвейере

**Состояние на момент записи**: `to-do` — 2026-09-26. Задача **открыта**, метки: `bug`, `P2`, `size:L`, `area:ci`, `release:identity-own`; родитель — волна-3 kaname#366. Работы по ней в ветке эпика нет. С 2026-09-25 несёт остаток п.3 закрытой задачи [[KAC/issue-393-kaname|#393]].

## Что и зачем

Перепись долга сквозного набора называет поимённо коллекции, которых не гоняет ни один шаг
конвейера и у которых нет держателя; четырнадцать из них принадлежат предмету платформы — краю
и чужим доменам. Задача — держатель этого долга для переписи [[KAC/issue-401-kaname|#401]]: у
каждой коллекции появляется дом по предмету и производитель в конвейере этого дома, исходов
три — переутвердить по фактическому производителю, перенести в платформу, снять вместе с
предметом.

Правкой тела 2026-09-25 сюда перенесён п.3 предиката #393 для `iam-role` и `iam-user`: три
отрицательных шага на свежем ресурсе, чей числовой вердикт на стенде должен не давать новых
падений по окну видимости. При закрытии #393 вместе с волной [[KAC/issue-358-kaname|#358]]
2026-09-26 новой задачи под этот остаток не заводилось — он здесь.

## DoD

Из тела задачи (перечислено как есть): каждая из 14 коллекций либо гоняется шагом конвейера,
либо отсутствует в дереве службы; перенесённую в платформу гоняет названный шаг её конвейера;
перепись долга не называет ни одну из 14. Для перенесённого из #393 — итог числами здесь и в
#393.
