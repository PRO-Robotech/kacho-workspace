## Что и зачем

**Признак.** Снятие веток по содержимому 2026-09-26 прошло во всех четырёх клонах — продукта,
службы доступа, фундамента и воркспейса: влитые и поглощённые сняты, каждое снятие — с bundle,
проверенным `git bundle verify` и `list-heads`. По телу задачи осталось 788 ссылок, у которых
разом: голова не предок ни одной цели; ветка не поглощена ни одной целью по файлам (каждый
файл, изменённый от merge-base, совпадает в цели по blob и mode); признаков живости нет (не
голова и не база открытого PR, не занята рабочей копией, не моложе 3 ч, задача не
`status:in-progress`).

| клон | осталось (единица — ссылка) |
|---|---|
| kacho | 454 |
| kaname | 74 |
| corelib | 5 |
| воркспейс | 255 |

Цели переписи и распределение несовпадающих файлов по клонам — в теле задачи. Там же сверка
тем же днём в других единицах счёта: corelib — 8 в единице «вне предка и вне поглощения» (из
них 5 без открытого PR), воркспейс — 308 в единице «все ссылки»; с таблицей выше эти числа не
складываются. Грязные рабочие копии
сняты в архив вне дерева, 73 копии, у каждой патчи, выкладка неотслеживаемого, `HEAD` и
контрольные суммы; сами копии не тронуты.

Известная слепота предиката — ветка отнесена к невлитым, хотя работа доехала: ветка влита
схлопыванием, а файл в цели потом правили; голова ветки — предок поглощённой головы.

**Предмет.** Каждой ссылке — один вердикт из трёх:

- **поглощена в иной форме** — содержимое в цели другим blob, после правки или схлопнутым PR;
  доказано по файлам либо по PR;
- **брошена** — содержимого, нужного продукту, нет; довод по содержимому, а не по возрасту;
- **жива** — работа нужна: у неё задача с номером, ветка сдаётся PR.

Снятие поглощённых и брошенных — только с bundle: `git bundle verify`, `list-heads` равно числу
снимаемых, проба восстановления в пустой репозиторий проходит. Незакоммиченное из архива
разбирается так же: живое — коммитом в ветку задачи.

## DoD

1. перепись по четырём клонам: ссылок без вердикта — 0; печатается объём — ссылок осмотрено и
   сколько по каждому исходу;
2. каждое снятие оставляет строку «bundle · sha256 · list-heads N = снято N»;
3. у каждой живой ссылки есть номер задачи, ни одна живая не снята;
4. каждая из 73 копий архива получила вердикт; живое сдано коммитом.
