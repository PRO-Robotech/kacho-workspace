# #2103: отказ, не восстанавливающий следующий шаг

**Предмет.** Вызывающий обращается к публичной поверхности службы, **не предъявив
удостоверения**, и получает отказ по правам. То есть ответ «тебя знают и не пускают»
приходит тому, кто ещё никем не назвался.

**Различать надо два состояния, и отвечали они по-разному только наполовину:**

- **предъявил, и не сошлось** — отказ аутентификации единственным побайтово равным текстом.
  Это верно и менять нельзя: различимый отказ здесь был бы оракулом;
- **не предъявлял вовсе** — отказ по правам. Вот это и есть предмет.

**Почему у отдельно поставленной службы это ломается.** Подсказку аутентификации на HTTP
производил **край**, а у выделенного продукта края нет **by construction** — вместе с ним
исчезает единственный производитель подсказки. Для арендатора чужого облака отказ по правам
не восстанавливает следующий шаг: он предлагает просить прав, тогда как нужное действие —
«назовись» — не называет вовсе.

Класс — ось разработчика из пяти вопросов ядра: *говорит ли отказ, что делать дальше*.

**Найдено по дороге** при письме приёмки собственного REST-фронта ([[KAC/issue-1109]]) и
заведено **своей** задачей: там решается, что фронт вообще существует, здесь — каким тоном он
отвечает. Сценарий приёмки записан **под производимое**, а желаемый тон заказан этой задачей —
иначе документ обещал бы поведение без производителя.
