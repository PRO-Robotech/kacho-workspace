# #2237: отказ, противоречащий сам себе

**Признак.** Сквозной прогон консоли: исполнено **98 из 98**, упала одна проба — «в строках
списка нет флажков и группового удаления». Текст отказа противоречил сам себе: «строк данных
**0**, меню **48**». Если бы строк не было, меню взяться было бы неоткуда.

**Предмет — проба, а не продукт, и не разборщик строк.** Разборщик верен: снимок DOM того же
отказа показывает 48 строк без единого служебного признака, а снимок страницы — меню у
каждой строки. Предмет в том, что **положительный контроль и утверждение читают DOM
порознь**: четыре отдельных обращения к странице, чьи числа сравнивались между собой. По
трассе того же прогона контроль прошёл на четвёртом опросе (**48**), утверждение прочитало
DOM уже внутри окна (**0**), а «всего строк» и «меню» — после него. Сообщение сложено из трёх
разных состояний одной страницы.

**Механизм окна назван, а не предположен.** Страница списка ролей открывается дважды: сперва
без области, затем — когда список аккаунтов доехал — с областью. Второй запрос идёт под
**другим ключом запроса**, поэтому на время его первой загрузки список показывает пустое
состояние; в снимке перед утверждением обёртка таблицы несёт признаки загрузки.

**Родство.** Это ровно тот класс, ради которого прежняя работа отделила строки данных от
строк устройства таблицы: тогда контроль пропускал вперёд ещё не дозагрузившуюся таблицу. Но
та правка сделала контроль **точным**, не сделав его **относящимся к тому же моменту**, что
утверждение.

**Радиус класса измерен, а не оценён:** по набору сквозных проб — 26 файлов, 23 обращения за
числом; сравнений «число из одного чтения DOM против числа из другого» — **одно**, вот это.

## Что сделано

Числа переписи берутся **одним обходом DOM**; два отрицания, выразимые только локаторами,
зажаты между двумя сошедшимися переписями; контроль и утверждение читают один снимок,
опрашивается только контроль.

Сама перепись живёт в общем источнике рядом с признаком строки данных, поэтому её несущее
свойство доказывается на **синтетическом теле**: четыре отдельных чтения воспроизводят
противоречивую тройку, одна перепись не даёт её **ни при каком порядке подмен**. Гейт проб
вырос с 5 утверждений до 10; три инъекции с контролем в обе стороны.

## Предикат снят прогоном, а не рассуждением

Сквозной прогон на ветке (отдельное задание, свой стенд): **исполнены все 98 объявленных
проб, упавших и пропущенных нет**; по отчёту — ожидаемых 98, неожиданных 0, нестабильных 0,
пропущенных 0. Перепись самой пробы на том прогоне — три списка, у каждого числа сошлись в
одном снимке; у списка ролей это те же **48** и **49**, что стояли в прежнем противоречивом
отказе, только третье число больше не ноль.

## Чего проверка не покрывает

Запрос в накопительную ветку конвейером не проверяется **by construction** — триггеры сужены
по стволу, — поэтому сквозной прогон гонялся отдельным заданием на ветке; вердикт о наборе в
стволе даст прогон линии. Локальный прогон перед отправкой: проверок исполнено **38**,
отказов 0, «не выполнено» 0.
