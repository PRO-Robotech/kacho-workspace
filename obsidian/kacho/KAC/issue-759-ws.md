# ws#759: README архива говорит «переселены» о разделе, которого нет

**Состояние на момент записи**: `to-do`. Задача **открыта**, PR нет
(`gh issue view 759 --repo PRO-Robotech/kacho-workspace --json state` → `OPEN`, 2026-09-22).
Метки: `tech-debt`, `P2`, `size:M`, `area:rules`, `release:wave`.

## Что и зачем

README архива утверждает, что **49 норм класса A** переселены в раздел «Доставка и общее дерево»
ядра корпуса. Раздела нет: у ядра четыре заголовка, и этого среди них не значится (перемерено
автором задачи 2026-09-22 в этом клоне, `grep -n '^#'`).

Держатель обещания установлен по истории: коммит, снявший 13 процессных файлов в архив
(«корпус 30 → 17 файлов»). Работа, которую он называет своим восьмым шагом, **не выполнена**, а
README читается так, будто выполнена. Читатель, которому нужны 49 норм, идёт по названному
адресу и не находит ничего — при этом отличить «нормы лежат в другом месте» от «норм нет нигде»
по этому тексту нельзя.

Чинить себя архив не будет: он **выведен из-под проверки свежести**, то есть единственный
механизм, ловящий такие расхождения, на него не смотрит.

**Отличие от соседей**: `#697` — адрес устарел, предмет существует; `#743` — то же семейство.
Здесь предмета по названному адресу **не было никогда**.

## Предикат снятия (из тела задачи)

**Либо** раздел существует и 49 норм в нём — число выведено **счётом норм в разделе**, а не
переписано из README; **либо** обещание снято, и README называет фактическое состояние.

Машинного держателя у предиката нет, пока архив вне проверки свежести, — поэтому исход
фиксируется в PR, а не наблюдением.

## DoD (из тела задачи)

- [ ] README архива и ядро корпуса согласованы: либо раздел с нормами, либо честная запись о состоянии;
- [ ] при переносе — заготовка исчерпана, и это показано счётом;
- [ ] принято решение, остаётся ли архив вне проверки свежести; если остаётся — причина названа в самом README.
