# kaname#188: неразличимость по времени — сделана в пределах класса, не сделана между классами

**Предмет.** Найдено пробой Ф3-31 ([[issue-1269]], PR kaname#179). Половина устройства
неразличимости по времени посажена: полосы «материала нет» и «адреса нет» выравнены значением
класса записи и сходятся с полосой проверки по критерию Ф1-48 (|Δ медиан| ≤ IQR большей полосы).
Вторая половина — выравнивание **между классами стоимости** — требует решения об устройстве, и
задача его не принимает: выбирает владелец, потому что один из двух вариантов меняет
наблюдаемую человеком задержку входа.

## Признак — воспроизводится одной командой

```sh
KACHO_LOGIN_TIMING=1 go test ./internal/apps/kaname/api/humansession/ -run TestLogin_F3_31 -count=1 -v -timeout 60m
```

Замер тела задачи (ревизия `db15cfc7`, N=12 обращений на полосу, чередование по кругу, отказов
по частоте 0): стоимости классов ID-PW-1 PWV-03 различаются между собой в **25–900 раз**, и
**18 из 21 пар** между классами критерий не проходят. Пары «материала нет» ↔ ручка и
«адреса нет» ↔ ручка — сходятся. Полная таблица медиан и IQR по семи полосам — в теле задачи;
здесь не воспроизводится, чтобы числа жили в одном месте.

## Два устройства, у каждого цена

| вариант | что делает | цена | критерий Ф1-48 |
|---|---|---|---|
| **огибающая по потолку** | всякий исход входа, включая успех, не раньше калиброванной при старте стоимости самого дорогого потолка перечня; ёмкость проверяющего отпускается до ожидания | задержка входа около секунды у каждого человека (на слабом поде — секунды) | выполняет |
| **огибающая по классу записи** | до стоимости ручки «что писать» | закрывает 4 пары из 21; потолок своего формата и соседний формат выдают себя (PWV-03 называет прямо) | не выполняет |

**Решения на 2026-09-17 нет:** комментариев в задаче ноль, исполнитель не назначен. Устройство
выравнивания ID-PW-1 отнесла к Ф3, а Ф3 назвала только критерий — поэтому предмет решения
лежит в приёмке Ф3 §4.2 либо в приёмке-преемнике, а не в коде.

## Предикат снятия

Проба выше — зелёная на всех 21 парах при IQR ниже потолка годности 250 мс; выбранное устройство
записано решением в приёмке Ф3 (§4.2) либо приёмкой-преемником — новой редакцией с записью
ревью, привязанной к отпечатку.
