# kaname#188: огибающая по потолку ФАКТИЧЕСКОЙ популяции

**Предмет.** Отказ на неверном пароле стоил столько, сколько стоит проверка хранимого значения, и
называл постороннему его класс — формат и параметры (ID-PW-1 Р4). Замер Ф3-31 на `6acf8f19`:
стоимости классов 0,9 мс … 843 мс, критерий Ф1-48 (`|Δмедиан| ≤ IQR большей полосы`) нарушен на
**18 парах из 21**.

**PR:** [kaname#216](https://github.com/PRO-Robotech/kaname/pull/216) в `release/iam-lines`; комментарий задачи с таблицей — issuecomment-5707107040.

**Решение оркестратора (владелец делегировал).** Вариант 1 — огибающая по потолку, где потолок берётся из
фактической популяции: `{классы, лежащие в хранилище} ∪ {класс ручки «что писать»}`, каждый —
калибровкой прогоном проверяющего при старте; пересчёт — когда чтение приносит класс, которого
перепись не видела. Статический потолок ID-PW-1 (bcrypt ≤ 14 и т. д.) остаётся границей ПРИЁМА, а
не задержкой. Запись решения в §4.2 Ф3 — параллельная полоса приёмок, не эта.

## Посылки задания — перемерены

- **Подтверждено:** 18 из 21 пар красных на `6acf8f19` (лог прогона до правки; медианы 0,89 мс / 837 мс / 34,8 мс / 188 мс / 17,3 мс / 33,8 мс / 53,4 мс).
- **Подтверждено:** «класс присутствует» нельзя узнать по индексу или колонке — их нет намеренно (миграция `20260915111233`); опровергнуто, что для этого нужна миграция: класс вычисляется базой одним последовательным проходом при старте, материал колонки не покидает. Миграции нет.
- **Уточнено:** повод `write` **не заведён**: все четыре писателя материала в дереве пишут классом ручки, допущенным при старте by construction; перенос П3 (`kacho#1268`) в дереве отсутствует — он и есть будущий вызывающий `Admit` при записи. Клетка, которую нечем поднять, лгала бы о провязке. Запись мимо процесса ловит повод `read` — окно оракула одно обращение.

## Что осталось — с носителем

- **§4.2 Ф3** — запись решения: параллельная полоса приёмок (не эта).
- **Перенос П3** (`kacho#1268`) обязан звать `Envelope.Admit` на класс каждой переносимой строки до записи и завести повод `write`; предикат: `git grep -n 'EnvelopeTriggerWrite' -- '*.go'` → непусто после его посадки.
- **Смена пароля** (`change_password.go`) проверяет текущий пароль без огибающей — вызывающий аутентифицирован своей сессией, оракула о чужой личности там нет; ID-PW-1/Ф3 её и не называют.
- Критерий Ф1-48 на выровненных полосах работает на уровне шума таймера (Δ ≤ 0,35 мс при IQR 0,1–0,8 мс): два прогона из двух зелёные; третьего прогона не было.
