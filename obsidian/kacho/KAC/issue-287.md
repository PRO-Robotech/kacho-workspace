# #287: перепись читала машинно собираемый файл как расщеплённую работу

**Type**: bug

**Состояние**: done — в составе релизной линии gates (PR ws#295).

**PRs**: PRO-Robotech/kacho-workspace#295
**Issue**: https://github.com/PRO-Robotech/kacho-workspace/issues/287

## Что и зачем

Указатель хранилища пересобирается генератором в каждой ветке, поэтому его дельта
со стволом непуста всегда. Перепись говорила правду буквально — файл не поглощён —
и лгала по существу: восемь находок из девяти были им.

Перечень машинно собираемого теперь **выводится**: у каждого генератора спрашивается
`--outputs`. Выписанный список отстал бы молча на втором выходе.
