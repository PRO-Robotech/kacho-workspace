# issue-240 — перепись веток принимает отставание за расщеплённую работу

**Status:** test — фикс влит в ствол коммитом `d245993`; нормы идут своим PR вместе с
[[KAC/issue-241]]. **Задача:**
[#240](https://github.com/PRO-Robotech/kacho-workspace/issues/240).

## Признак

Перепись судила одним признаком — дельтой пробного слияния, — а он **асимметричен**: пустая
дельта доказывает поглощение, конфликт не доказывает ничего. Конфликт одинаково означает и
«ветка несёт своё», и «ствол правил тот же файл дальше».

Замер на монорепо продукта (`origin/main@cd7bcc5c`, 2026-08-16): раздел «PR закрыт, а работа
в стволе НЕ ВСЯ» — **12** веток, из них настоящих **7**. Доля ложных — **42 %**.

## Почему это не косметика

Перепись — единственное, что стоит между `git branch -D` и работой, существующей в одном
экземпляре. Инструмент с 42 % ложных находок перестают читать; перестав читать,
возвращаются к `git branch --merged`, а он здесь даёт **ноль** при 63 ветках, из которых 13
влиты.

## Решение: два признака, врущие в разные стороны

| проверка | что доказывает | где врёт |
|---|---|---|
| обратное применение патча файла во временный индекс ствола | поглощение | ложно отрицает, когда ствол правил тот же файл после вливания |
| блоб ветки в истории ствола (`git log --find-object`) | содержимое проходило через ствол | молчит, когда PR правился по ревью |

Файл непоглощён, только если **обе** сказали «нет». Патч кладётся в **временный индекс**
(`GIT_INDEX_FILE`), не в индекс репозитория: испорченный индекс заставляет проверки,
читающие дерево, выдумывать красные вердикты.

## Вторая половина предмета: стволов больше одного

Перепись сравнивала только с `origin/main`, а работа копится в накопительных ветках. Из-за
этого две ветки, честно влитые в `origin/release/gates-and-findings`, объявлялись
неслитыми. Перечень стволов теперь **выводится** из ссылок `origin/release/*`, а не
выписывается.

## Замер до/после

| | было | стало |
|---|---:|---:|
| влитых | 20 | **29** |
| в единственном экземпляре | 17 | **8** |
| с расщеплённой работой | 12 | **7** |

Положительный контроль (`issue-352`) уцелел в обоих разделах — иначе зелёное означало бы
«перепись перестала находить вообще».

## Чем держится

`scripts/branch-audit-inject.sh` — 18 утверждений; по шестому признаку пара:
**K** (поглощено, ствол правил тот же файл после → молчание) и **L** (законный близнец того
же силуэта, содержимого ствол не видел → находка с именем). Без **L** шестой признак глушил
бы настоящую работу заодно с ложной.
