# ui-future/deploy → зонт: подчарт `uif`, подключённый путём в дереве

**Форма ребра**: зависимость чарта, объявленная **путём в том же дереве**
(`file://../../../ui-future/deploy`), а не ссылкой на хранилище чартов. Путь не зависит от
ветки: любая рабочая копия монорепо разрешает его одинаково.

| ось | значение на 2026-09-22 |
|---|---|
| имя подчарта | `uif` |
| координата объявления | `deploy/helm/umbrella/Chart.yaml:114-117` |
| условие | `uif.enabled`, по умолчанию выключено |
| собранный экземпляр | `deploy/helm/umbrella/charts/uif-2.0.0.tgz` |

## Что из имени следует

Ресурсы подчарта именуются из его значений (`uif`, `uif-dashboard`, …), совпадая с
самостоятельным выпуском, который зонт замещает. Включение подчарта на кластере, где уже
работает самостоятельный выпуск, требует одноразового перенятия владения существующими
ресурсами; сетевой ресурс, заведённый вне зонта, при этом не трогается.

## Сцепление, из-за которого ребро названо

Раздача консоли обслуживает потоки личности **условно**, и условие держит рендерный гейт
каталога [[packages/kacho-deploy-tests-helm]]: он судит **пару** «объявлен браузерный адрес
потока × полоса, которая его отдаёт». Отсюда неделимость уборки:

- подчарт чужой консоли снимается;
- рукоятка `uif.host.upstreams.kratosUi` опустошается;
- объявления браузерного адреса потока в шаблоне личности зонта снимаются.

Любая из трёх координат **в одиночку** оставляет объявленный поток без раздатчика и красит
гейт. Три задачи, одно изменение, один прогон — предмет [[issue-2777]].

На 2026-09-22 на посадках `prod` и `own` подчарт выключен, а объявления адреса потока ведут на
внешний хост: то есть условие выполнено в сторону чужой консоли, а не своей.
