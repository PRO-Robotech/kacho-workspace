# Перепись покрытия, слепая к глаголу заведения

**Признак.** Гейт утверждает полноту («покрыт каждый ресурс API», «у каждого сервиса есть
X»), а список предметов выводит из дерева **по имени операции**: ищет `Create`, попутно
вспоминает `Issue`, потому что где-то видел выпуск ключа. Число, которое он печатает,
выглядит измеренным — но оно измерено не по предмету, а по **словарю имён, который держит в
голове автор гейта**. Один сервис заводит свой ресурс глаголом `Invite`, и он не попадает в
перепись **вовсе**: не «покрыт частично», не «в долгах» — его нет в знаменателе.

Отличительная примета: знаменатель гейта — величина, полученная фильтром, а не полным
разбором. Спросите «а что этот фильтр выбросил?» — у гейта нет ответа, потому что
выброшенное он не считает.

## Отличие от похожего

От [[lessons/absence-of-finding-versus-absence-of-inspection]] отличается тем, где теряется
предмет. Там неосмотренный путь смешивается с чистым в **результате**; здесь предмет не
доходит до осмотра — он выпадает **на входе**, и потому не попадает ни в находки, ни в
объём осмотренного. Печать «осмотрено N сервисов» такой дефект не ловит: N уже занижено.

От обычной ошибки в регулярном выражении отличается направлением ущерба. Ошибка в разборе
обычно даёт ложную находку — её замечают. Эта даёт **ложную полноту**: чем больше ресурсов
покрыто на самом деле, тем убедительнее выглядит «24 из 23».

## Противоядие: классифицировать ВСЁ множество, а не выбирать из него

- **Два списка вместо одного фильтра.** Заводящие глаголы — поимённо; **все остальные** —
  тоже поимённо. Глагол, не попавший ни в один список, **роняет гейт**. Тогда следующее
  слепое пятно не заводится молча: оно заводится красным.
- Второй список выписывается **механически из дерева** и обязан за ним следовать — иначе он
  сам становится памятью автора, только длиннее.
- **Перезамер сразу после починки предиката** — часть починки, а не следующий шаг: именно он
  показывает, что число было ложным, и называет пропущенное.
- Печатать обе стороны переписи (найдено предметов · покрыто), а не долю: доля скрывает, что
  менялся знаменатель.

## Где наблюдалось

`PRO-Robotech/kacho`, 2026-08-12, гейт паритета Terraform-провайдера с публичным API
(`internal/repohygiene/terraformresourceparity_test.go`, коммит `6c1781c0`). Первая редакция
искала сервисы с глаголами `Create` и `Issue`; пользователь заводится `Invite`, и весь его
сервис в перепись не входил. Объявленное покрытие «17 при 23 найденных» было измерено по
заниженному знаменателю. После починки: все **75** глаголов публичного API расписаны на два
списка, покрытие — **24 из 24 при одном названном долге**.

## Чем это держится

Гейт роняется тремя способами сразу: глагол вне обоих списков; запись таблицы, чей сервис из
контрактов исчез; ресурс провайдера без создающего сервиса. Плюс отказ вместо вердикта при
нулевом результате переписи («ноль здесь означает сломанный обходчик, а не чистое дерево») и
печать объёма осмотренного. Долги самоистекают: появился ресурс — запись долга становится
находкой.

Норма — `.claude/rules/testing.md` §«Гейт на класс: измерить по дереву, доказать инъекцией,
снабдить проверкой предпосылки»; предмет здесь — **наблюдение**, а не переизложение нормы.
