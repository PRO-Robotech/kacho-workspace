# Своя команда проверки судила о другом проекте

**Признак.** Проверка типов, запущенная своей рукой, отвечает «ошибок 0», а прогон **проб**
того же пакета падает разбором — на синтаксической ошибке, в файле, который эта проверка
только что признала чистым. Соблазн — винить пробы («другой транспилятор», «другой
конфиг»). Различие не в строгости, а в том, **какой проект был прочитан**.

**Механика.** Конфигурация пакета ссылочная: корневой `tsconfig.json` не перечисляет
исходники, он ссылается на подпроекты, и `npm run typecheck` пакета зовёт `tsc -b`
(построение по ссылкам). Одиночный `tsc --noEmit -p tsconfig.json` читает **корень** —
проект без файлов. Ноль ошибок он выдаёт честно: он ничего не прочитал.

Второе усиление: `tsc -b` держит `.tsbuildinfo`. Пока метка времени не изменилась, повторный
прогон отвечает по кэшу — и после правки чужой сессии отвечает о дереве, которого уже нет.

**Отличие от похожего.** Это не [[verdict-of-a-tool-belongs-to-its-version]]: версия одна и
та же. И не «локально другие флаги»: флаги здесь ни при чём. Предмет — **множество
прочитанных файлов**, и оно не печатается ни одной из двух команд, поэтому расхождение
ничем себя не выдаёт.

**Противоядие.**
1. **Зови ту команду, что зовёт конвейер** — `npm run typecheck` пакета, а не свой `tsc`.
   Своя команда удобнее ровно тем, чем опаснее: она короче, потому что решает меньше.
2. **Перед замером сноси `.tsbuildinfo`**, если дерево трогали другие. Кэш построения — это
   вердикт о прошлом состоянии, поданный как вердикт о текущем.
3. **Считай прочитанное.** Проверка, не печатающая объём осмотренного, не позволяет отличить
   «чисто» от «не смотрел»; для чужого инструмента заменителем служит **вторая** проверка на
   том же дереве другой природы — здесь непрочитанный файл нашли пробы, а не типы.

**Где наблюдалось.** Консоль, ветвь `issue-373`: `tsc --noEmit -p tsconfig.json` по десяти
пакетам дал «зелено», после чего пробы `compute` не собрались — комментарий JSX стоял в
позиции выражения тернарного оператора. Тот же заход вторым слоем показал три пакета, чей
результат хука списка вовсе не имеет поля, которое правка у него читала: `tsc -b` пакета
это назвал, одиночный прогон — нет.
