# Руководства (docs/) — история намерения, а не инструкция

Три страницы, заведённые под эпик [[KAC/KAC-127]] как черновики публичной
документации: администратору, пользователю, разработчику-интегратору.

| Страница | Для кого | Состояние |
|---|---|---|
| [[docs/admin-iam-guide\|Admin IAM guide]] | администратор организации | `legacy` — описывает снятые подсистемы |
| [[docs/user-iam-guide\|User IAM guide]] | конечный пользователь | `legacy` |
| [[docs/dev-iam-integration\|Developer IAM integration]] | интегратор | `legacy` |

> [!warning] Публичного адреса, который эти страницы обещают, не существует
> В шапке каждой стоит будущий публичный URL. Отдельного сайта документации по
> этим разделам в дереве нет; регламент документации продукта — скил
> `kacho-docs-writer`, и место готовой документации — сайт сервиса, а не эта
> папка.
>
> Половина содержания описывает подсистемы, **снятые с продукта**: внешний
> провижининг учётных записей, мост к внешнему SAML-провайдеру, организации как
> уровень иерархии, конвейер событий безопасности. Проверено 2026-08-05 по дереву
> `b4edc5d5`: соответствующие таблицы дропнуты миграциями
> `services/iam/internal/migrations/0006…0008`, контрактов в
> `proto/kacho/cloud/iam/v1/` — ноль файлов. Иерархия сегодня двухуровневая:
> аккаунт → проект.
>
> Страницы **не удалены**: по ним видно, какой продукт проектировался, и на них
> ссылается журнал. Каждая несёт предупреждение в собственном заголовке — читать
> как историю.
