# Манифест домена: права, роли и модель доступов из одного YAML

Клиент, поставивший iam в своё облако, пишет YAML и получает работающие права
на **свои** ресурсы. Сегодня это невозможно: каталог типов зашит в Go, и
незнакомый модуль отвергается на пути запроса.

Задача — [[KAC/issue-1087]]. Доказательная база и инструменты —
`docs/manifest-dcl/` этого репозитория; там же сказано, что в неё **не сдано**
и почему.

> [!important] Числа ниже относятся к РЕВИЗИИ снимка, а не к сегодняшнему дереву
> Снимки проработки сняты на `kacho@8fab73ab` (2026-08-23) и за девять дней
> разошлись со стволом: отношение `use` снято из модели задачей
> [#1115](https://github.com/PRO-Robotech/kacho/issues/1115), каталог прав
> прирос семью записями. Расхождение называет `docs/manifest-dcl/tools/drift.py`
> — прогоняй его прежде, чем брать отсюда число.

## Форма

Шесть разделов верхнего уровня:

```yaml
apiVersion: iam/v1
module: vpc
resources:        # ресурсы, их действия и классы
deprecatedVerbs:  # принимаем на чтении, не производим
roles:            # роли полями, а не строкой
seed:             # что заводит установка модуля
```

**Роль описывается полями**, а не строкой `vpc.network.*`: строка есть второй
язык поверх манифеста и ломается молча — снял глагол, строка осталась годной
по форме и пустой по существу. Поля сверяются с перечнем ресурсов без разбора
текста.

**Выдача взята дословно у `CreateAccessBinding`** — `subjects[]` 1..32,
`roleId`, `scopeType`, `scopeId`, `target`. Не потому, что короче, а потому,
что иначе манифест заводит второй словарь для того же предмета.

## Что выводится, а не пишется

| выводится | из чего |
|---|---|
| класс действия | точное совпадение с `get·list·create·update·delete` |
| область проверки | из класса: `create` и `list` — на родителе, прочее — на объекте |
| тип объекта модели | `<module>_<resource>`, если не объявлен `objectType` |
| указатель на родителя и каскад | из `parent` |
| три базовые роли | из классов |
| порядок установки модулей | из `joins` |

## Что доказано

| ось | итог |
|---|---|
| блоки типов против модели `8fab73ab` | **побайтово**, 5932 Б, md5 `17409a0052ae…` |
| строки `define` против блоков `c7467b21` | 0 расхождений — после снятия `use` из манифеста |
| записи каталога прав vpc | 95 / 95, дублей 0 |
| действующие системные роли vpc | 18 / 18 воспроизводимы |
| операции каталога Kachō | 340 / 340, склеек 0, лишних прав 0 |
| инъекций: валидатор · схема · эмулятор · замер отставания | 38 · 31 · 9 · 4 |

Побайтово — не «по смыслу». Три вещи, без которых равенства не выходит, нашла
сама сверка: комментарий блока воспроизводится дословно · порядок ресурсов
задаёт модель · хвостовой перевод строки тоже байт.

**И ровно поэтому на сегодняшнем стволе побайтового равенства уже нет.** Место
снятого `use` заняли шесть строк прозы о снятии; генератор прозы не производит.
Ось доказательства сместилась туда, где она про контракт: строк `define`
расходится **0**, строк всего — **7**. Байтовое равенство названо вместе со
своей ревизией, а не в настоящем времени.

## Границы — названы, а не умолчаны

- **`subjects` воспроизводит текст, но не поведение.** Резолвер прямой список
  игнорирует: `[user]` и `[user, service_account, group#member]` дают
  побайтово один план. Писать надо — модель есть контракт, — считать сужением
  нельзя.
- **JSON Schema судит форму.** Связность держит валидатор: субъект заведён
  этим же посевом · роль существует · группа кому-то выдана · **ключ остался
  строкой после разбора YAML**.
- **Преднастроенной выдачи ролью в продукте нет ни одной из 5469.** Все 3335
  системных выданы отношением, все 2134 обычных ролью, без исключений в обе
  стороны.
- **Действия ресурса называются двумя словами, и это не решено.** Рукописный
  манифест пишет `verbs` — его читают все три инструмента, на которых стоят
  доказательства; порождённые манифесты пишут `actions` — его читает один
  эмулятор. Предикат и следствие — в README проработки; сведение к одному слову
  заведено отдельно, чтобы не двигать числа сходимости заодно.

## Развилка — ЗАКРЫТА решением (ветка A)

Ветка **A**: манифест порождает блоки типов, модель растёт с каждым доменом.
Ветка **B**: модульные типы не рендерятся вовсе, один параметрический тип,
горячий путь вердикта каталога не читает никогда. Взаимоисключающи по тому, что
попадает в текст модели; ошибка направления не правится — работа выбрасывается.

Выбрана **A**, задача развилки закрыта, доказательная база — этот каталог.
Здесь стояло «не закрытая решением»; утверждение пережило своё решение и
правится тем же изменением, каким доказательство сдаётся в git.

## Второй корпус — в дерево НЕ сдан

Выразительность схемы проверялась ещё и на каталоге стороннего публичного API:
168 операций, сходимость 100 %, склеек 0. Сам корпус и работавшие с ним
инструменты в репозиторий не сданы: они называют чужого облачного провайдера, а
это запрещено вторым непереговорным. Значит 168 — **запись о проработке**, а не
воспроизводимый предикат; подавать его как проверку нельзя. Воспроизводится
сегодня половина Kachō: 340 / 340.
